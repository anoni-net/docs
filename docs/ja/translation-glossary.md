# :material-book-alphabet: 訳語の方針

日本語版の訳文を直してくださる方に向けたページです。**善意の校訂が既存の方針とぶつからないように**、判断基準を先に公開しておきます。

ここに書かれていない語は自由に判断してください。方針そのものへの異論も歓迎します。[GitHub の Issue](https://github.com/anoni-net/docs/issues){target="_blank"} でご指摘ください。

## 大原則

- **原文は繁体字中国語版（zh-TW）です。** 各ページの末尾に対応する原文へのリンクがあります。訳が原文とずれている場合、原文が正です。ただし在地化のため意図的に変えた箇所があります（下記）。
- **文体は敬体（です・ます）**。箇条書きの項目と表のセルは体言止めでかまいませんが、同じリスト内では揃えてください。
- **逐語訳より、日本語として読めることを優先します。** 原文の構造を保つために不自然な日本語になるくらいなら、構造を変えてください。

## 訳さない語

技術用語と製品名は英語のまま置きます。カタカナに直しません。

`Tor` `Tails` `OONI` `ASN` `VPN` `DNS` `DoH` `DoT` `DoQ` `TLS` `SNI` `ECH` `PGP` `Signal` `Telegram` `LINE` `WeChat` `Matrix` `Cryptpad` `IPFS` `Yggdrasil` `DN42` `I2P` `SecureDrop` `YubiKey` `uBlock Origin` `Pulse` `single source of truth`

Tor リレーの役割名（`guard` `middle` `exit`）も英語のままです。日本語の定訳が定まっておらず、Tor の設定ファイルや公式文書でそのまま現れる語だからです。

## 表記の規則

- **カタカナの複合語は分けて書きません。** 「メールアドレス」であって「メール アドレス」ではありません。中黒（・）は並列の語をつなぐときだけ使います。
- **英数字の前後に半角スペースを入れます。** 「稼働中 66 台」「2026 年 7 月」「AS63806 に 8 台」のように。日本語と英数字の境界だけで、句読点との間には入れません。
- **数はアラビア数字**。「4 つの言葉」であって「四つの言葉」ではありません。慣用句（一つ一つ、二人）は例外です。
- 本文の句読点は「、」と「。」。感嘆符は使いません。

## 法律名の扱い

台湾や他国の法律は、**日本語の概念語を先に置き、原名を残します**。

- 揭弊者保護法 → 「内部告発者を保護する揭弊者保護法」
- 個人資料保護法 → 「個人資料保護法（日本の個人情報保護法にあたる法律）」（初出のみ併記）

台湾での口語的な略称（「個資法」など）は使いません。日本語の読者には通じません。

## 安全に関わる記述

DV、社会運動、情報源の保護といった場面を扱う箇所は、**語り口を軽くしないでください**。当事者を責める書き方、行動を急かす書き方は避けます。相談窓口の電話番号や制度名は、必ず一次情報（省庁や公的機関のページ）で確認してから直してください。
