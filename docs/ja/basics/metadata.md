# :material-file-tree: メタデータはなぜ危険か

「端末間暗号化を使っているから、誰もメッセージを読めない。だから安全だ」。前半は正しく、問題は後半にあります。メタデータは、その後半が崩れる場所です。

メタデータは文字どおり「データについてのデータ」です。電話をかけたとき、**通話の内容**がデータで、**相手、時刻、場所、通話時間**がメタデータです。内容が暗号化されて誰にも読めなくても、メタデータだけでその人の交友関係、行動パターン、生活の軌跡を復元できます。多くの脅威モデルでは、メタデータのほうが実際の破れ目になります。

このページでは、メタデータがどこから生まれるのか、なぜ直感より危険なのか、そして露出を減らす基本的なやり方を説明します。

## よく引用される一言

> 「我々はメタデータに基づいて人を殺している。」

米国家安全保障局（NSA）と中央情報局（CIA）の元長官である Michael Hayden が 2014 年の公開の場で述べたものです。言おうとしているのは、多くの場面では「誰と誰が、いつ、どこで通信したか」を知るだけで判断が下せて、内容を読む必要はない、ということです[^1]。

この言葉は物騒に聞こえますが、そこで明かされている事実は日常生活にも同じく当てはまります。メタデータは国家規模の監視だけが気にするものではありません。広告事業者、プラットフォームのアルゴリズム、保険会社、元交際相手を追う人、身元を特定しようとする匿名の第三者は、どれも同じ原料を使っています。

## まず対照表で

誰かがあなたを監視したいとして、次の場面で何が見えるかを並べます。

| 場面 | 内容 | メタデータ |
|---|---|---|
| 記者と 30 分の暗号化通話をした | 通話の内容（暗号化されていて見えない） | あなたが今夜ある記者と 30 分話した |
| 弁護士に PGP 暗号化メールを送った | 本文（暗号化されている） | あなたがある法律事務所と継続的に連絡している |
| 社会運動の仲間に Signal でメッセージを送った | メッセージの内容（端末間暗号化） | あなたがこの集団と友だち関係にあり、やり取りの頻度が高い |
| Tor である機微なサイトを見た | 何を見たか（Tor が切り離している） | ISP には「あなたが Tor を使っている」ことが見え、目的のサイトには「ある Tor 出口ノードがアクセスした」ことが見える |

各行の左側は暗号化されていますが、右側はたいてい暗号化されていません。多くの脅威にとって、右側だけで判断を下すのに十分です。

## メタデータはどこから生まれるか

メタデータは日常のさまざまな行為の副産物で、あちこちに散らばっており、集中した単一の出所はありません。

### 通信

- **電話**：発信と着信の番号、時刻、通話時間、基地局の位置
- **SMS**：送信者、受信者、時刻、長さ
- **電子メール**：送信者、受信者、CC、時刻、メールのサイズ、件名（多くの場合は暗号化されません）
- **メッセージング**：誰と誰が友だちか、やり取りの頻度と時刻、グループのメンバー一覧

注意すべき点として、内容が端末間暗号化されていても、上に挙げたものはたいてい暗号化されません。Signal はこの種のメタデータ収集を意図的に減らしている数少ない道具ですが、それでも完全には消せません（登録に電話番号が必要で、それ自体が身元の手がかりになります）。Signal は 2024 年からユーザーネームを提供しており、連絡先に電話番号を明かさずに済み、電話番号での検索を無効にもできるので、露出の一部は減らせます。登録に電話番号が要るという前提は変わらないため、完全な匿名性が必要な場面では制約が残ります。

!!! info "日本の読者への注記：LINE の場合"

    日本ではメッセージングが LINE に強く集中しています。これはメタデータの観点では固有のリスクを生みます。**誰と誰が、どのくらいの頻度でやり取りしているか**という関係の地図が、ほぼ単一の事業者のもとに集まるからです。相手ごとにアプリが分かれている環境より、一箇所に集約されているぶん復元が容易になります。

    LINE の端末間暗号化は Letter Sealing と呼ばれます。LINE ヤフーが公開している[暗号化状況レポート](https://www.lycorp.co.jp/ja/privacy-security/security/transparency/encryption-report/2025/){target="_blank"}によれば、1 対 1 のトークと 1 対 1 の音声・ビデオ通話には Letter Sealing による端末間暗号化が適用されます。一方で**グループ音声通話、グループビデオ通話、LINE ミーティングは通信路の暗号化のみ**で、端末間暗号化ではありません。設定の確認方法は [LINE ヘルプセンター](https://help.line.me/line/smartphone?lang=ja&contentId=50000087){target="_blank"}にあります。

    ここで押さえてほしいのは、Letter Sealing が有効かどうかとは別に、**このページで扱っているメタデータはどちらにせよ保護されない**ということです。内容の暗号化は内容だけを守ります。誰といつやり取りしたかは、その外側に残ります。

### ファイル

- **写真**：EXIF 情報（撮影時刻、カメラの機種、GPS 座標）、サムネイル
- **PDF / Word**：作成者、変更履歴、最終編集者、埋め込みフォント、直前のファイルパス
- **録音・録画**：タイムスタンプ、機器の型番

### ネットワーク

- **閲覧履歴**：どのドメインをいつ訪れ、どれだけ滞在し、どこから来たか
- **DNS クエリ**：端末がどのアドレスを問い合わせたか（多くの場合は暗号化されていません）
- **TLS SNI**（接続の確立時に、どのサイトへ繋ぎたいかをサーバーへ伝える欄）：HTTPS でも、このドメイン名はハンドシェイクの平文に残ります
- **IP アドレス**：接続時に外部へ出る住所で、地理的な位置と強く相関します

近年は Encrypted Client Hello（ECH、TLS ハンドシェイク内の宛先ドメイン名も暗号化する仕組み）が SNI の部分を変えつつあります。Firefox 119 と Chrome 117 以降は既定で対応し、Cloudflare などの CDN も対応しています。ただしサーバー側の対応が要り、暗号化 DNS（DoH）環境で最も効果を発揮し、中間機器に阻害されることもあります。すべての接続で SNI が保護されていると仮定することはまだできません。

### システム

- **ログイン履歴**：いつ、どの端末で、どの IP からどのサービスにログインしたか
- **決済の記録**：カード利用の時刻、場所、金額、送金相手
- **端末のセンサー**：スマートフォンの GPS、Wi-Fi スキャン、Bluetooth 周辺機器の一覧（位置情報を自分で共有していなくても残ります）

## なぜ直感より危険なのか

### 明かすつもりのないことが明らかになる

「弁護士とやり取りしているが、内容は二人しか読めない」は厳重に聞こえます。しかし「あなたがある法律事務所と長期にわたり連絡している」という事実そのものが、「何らかの法的な問題を抱えている」ことを漏らします。相手は中身を読む必要がなく、通信の時系列を見れば足ります。

### 複数の出所を突き合わせられる

単一の出所では無害でも、いくつか突き合わせると性質が変わります。

- カードの利用履歴、スマートフォンの位置情報、SNS のチェックインを合わせると、その週の行動範囲が復元できます
- 閲覧履歴、写真の EXIF に残る GPS、クラウド文書の編集時刻を合わせると、仕事の進め方が組み立てられます

広告業、データ仲介業、捜査機関の照会、そして匿名の第三者による身元特定は、いずれもこの突き合わせに依存しています。

### 道具の既定値がたいてい保存する側に倒れている

- カメラアプリは既定で GPS を有効にしています
- メッセージングアプリは既定で履歴を保持します
- クラウドサービスは既定で複数端末に同期し、版の履歴も残します
- ブラウザは既定ですべての cookie と自動入力を覚えます

**既定値こそが最大のメタデータ源です。** 多くの人は設定を変更しません。

### 暗号化の外側にある

暗号化は内容を守りますが、その外側はたいてい守りません。PGP 暗号化メールの本文は解読不能でも、送信者、受信者、件名、時刻は見えます。Tor 接続はあなたと宛先の対応を切り離しますが、契約している ISP には「あなたが Tor を使っている」という事実が見えます。

## 露出を減らす基本的なやり方

完全に消すことはできませんが、減らすことはできます。以下は自分で着手できるもので、費用の低い順に並べています。

### 費用が低い（誰でも今すぐできる）

- 写真をアップロードする前に EXIF を落とす（スマートフォンの共有時に位置情報を含めない選択ができます）
- 文書を共有する前に「名前を付けて保存」か専用ツールでメタデータを除去する
- メッセージングは既定でメタデータを集めない設計のものを選ぶ
- メッセージングアプリの「アルバムへ自動保存」「メディアの自動ダウンロード」を切る

### 費用が中くらい（設定に少し時間がかかる）

- パスワード管理ツールを使い、サービスごとに別の認証情報にして、アカウント同士が結びつくリスクと一度に破られるリスクを下げる
- ブラウザに uBlock Origin のような追跡ブロック拡張を入れる
- DNS を暗号化に対応したもの（DoH / DoT）に切り替える。この一手で変わるのは**誰があなたのクエリを受け取るか**であって、接続そのものが匿名になるわけではありません
- 決まった相手には一貫した道具を使い、複数のプラットフォームに対応関係を残さない

### 費用が高い（特定の場面では見合う）

- 機微な作業には Tails を使い、毎回きれいな環境から始める
- 観察されうる相手には Tor Browser でアクセスする
- 身元ごとに独立した端末かアカウントを維持する（メールや端末を共用しない）
- 重要な紙の文書はオフラインの手順で扱う
