# :material-lightbulb-outline: 基本概念

このサイトの概念層は意図的に薄く作っています。anoni.net にたどり着く読者の多くは Tor や OONI が何かをすでに知っているか、[EFF Surveillance Self-Defense](https://ssd.eff.org/){target="_blank"} や [Privacy Guides](https://www.privacyguides.org/){target="_blank"} といった入門資料にアクセスできます。私たちはその仕事を重複させません。

概念層で私たちが公開するのは、サイトの他の部分を読むために必要な枠組みです。具体的には、**アジア太平洋の中国語圏においてネットワークの自由がなぜ問題になるのか**、そして **anoni.net が接続、アイデンティティ、資金の流れの関係をどう捉えているか**です。加えて、定評ある教材にも隙間はあります。個別の概念を単独で説明するより、並べて比べたほうが役に立つ場面です。私たちはそこを埋めています。

## 収録記事

この 3 本は続けて読むと噛み合います。まず言葉を分け、次に暗号化の外側に何が残るかを見て、最後に自分の場合はどれが問題になるのかを決める、という順序です。

- [匿名・プライバシー・仮名・機密](./anonymity-vs-privacy.md) — 同義語のように使われる 4 つの言葉が、それぞれ別のものを守っています。道具を選ぶための一枚の対照表を、アジア太平洋と日本の事例とともに。
- [メタデータはなぜ危険か](./metadata.md) — 暗号化が隠してくれない付随情報（誰と、いつ、どのくらいの頻度で、どこから）。日本の読者向けに LINE の Letter Sealing がどこまで守るのかも整理しています。
- [脅威モデルの立て方](./threat-model.md) — 何を守り、誰から守り、どこまでコストを払えるか。立場ごとの例と、日本の相談窓口つき。

以下のページは現在、英語版と繁体字中国語版のみです。

- [ネットワークの自由がなぜ重要か](https://anoni.net/docs/en/basics/internet-freedom/){target="_blank"}（英語）— 東アジアと東南アジアという地域的な枠組みと、anoni.net の 3 つの観測軸（接続層、個人データとアイデンティティ層、資金の流れの層）。
