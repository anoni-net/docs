# :material-lightbulb-outline: 基本概念

anoni.net にたどり着く読者の多くは Tor や OONI が何かをすでに知っているか、[EFF Surveillance Self-Defense](https://ssd.eff.org/){target="_blank"} や [Privacy Guides](https://www.privacyguides.org/){target="_blank"} といった入門資料にアクセスできます。私たちはその仕事を重複させません。

定評ある教材にも隙間はあります。個別の概念を単独で説明するより、並べて比べたほうが役に立つ場面です。日本語版はまずそこを埋めています。あわせて、日本の制度に接続する記述を各ページに加えました。原文にはない部分です。

## 収録記事

まず[ネットワークの自由](./internet-freedom.md)で、このサイトが何を見ているのかの枠組みを押さえてください。そのうえで次の 3 本を続けて読むと噛み合います。言葉を分け、暗号化の外側に何が残るかを見て、最後に自分の場合はどれが問題になるのかを決める、という順序です。

- [ネットワークの自由](./internet-freedom.md) — 接続、個人データ、資金の流れという 3 つの層。東アジアと東南アジアの状況と、**日本から読む場合にどこが効いてくるか**。
- [匿名・プライバシー・仮名・機密](./anonymity-vs-privacy.md) — 同義語のように使われる 4 つの言葉が、それぞれ別のものを守っています。道具を選ぶための一枚の対照表。**日本の携帯電話不正利用防止法**との接続つき。
- [メタデータはなぜ危険か](./metadata.md) — 暗号化が隠してくれない付随情報（誰と、いつ、どのくらいの頻度で、どこから）。**LINE の Letter Sealing がどこまで守るのか**も整理しています。
- [脅威モデルの立て方](./threat-model.md) — 何を守り、誰から守り、どこまでコストを払えるか。立場ごとの例と、**日本の DV 相談窓口**つき。
