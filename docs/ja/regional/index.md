# :material-map-outline: 地域観測

アジア太平洋の中国語圏はひとつの規制環境ではありません。中国大陸、香港、マカオ、シンガポール、マレーシア、台湾、そしてその間を移動する人々のあいだで、言論、身元、決済、接続を律するルールは大きく異なります。この違いは、その地域で報道、アドボカシー、研究をする人にとっても、単に国境をまたいで私生活を送りたい人にとっても実際に効いてきます。

私たちは台北にいます。この位置には特有の価値があります。台湾の接続環境は地域のなかでも開かれているほうでありながら、条件がもっと厳しい複数の法域と言語、家族のつながり、プラットフォームの生態系を共有しています。この視点から、観測、規制、実際の運用の 3 つを追っています。

!!! warning "日本は観測対象ではなく参照点です"

    誤解を避けるために先に書いておきます。**私たちは日本の法制度や言論環境を観測していません。** 日本が登場するのは Tor リレーの監視においてだけで、これは地域の参照点として台湾、香港、韓国と並べているものです。

    日本の読者にとってこのセクションの価値は、日本の状況を知ることではなく、**隣接する法域で何が起きているかを中国語の一次情報を読める位置から見た記録**にあります。中国大陸の検閲技術が国外へ輸出される動き、香港の国家安全維持法以降の変化、越境時の端末検査といった論点は、日本の事業者、研究者、報道関係者にとって無関係ではありません。

## :material-eye-outline: どこまで語れるか

法域によって私たちの立ち位置は違います。地域全体に同じ深さがあるとは主張しません。以下のカードは、それぞれの部分についてどれだけ直接的に語れるかで分けています。

### 私たちが立っている場所

<div class="grid cards" markdown>

- :material-island:{ .lg .middle style="color: var(--brand-cyan-500);" } **台湾**

    ---

    コミュニティは台北にあり、一次的な立場で語れる唯一の法域です。詳しく追っている規制は 3 本あります。2025 年の個人資料保護法（日本の個人情報保護法にあたる法律）の全面改正（および新設の個人資料保護委員会）、登録制から許可制へ移行する 2026 年の VASP 法、そして内部告発者を保護する揭弊者保護法の技術的な側面です。近隣の法域より条件が開かれている傾向があるため、中国語圏の基準点としても使えます。

- :material-source-branch:{ .lg .middle style="color: var(--brand-cyan-500);" } **台湾のオープンソースとシビックテックの場**

    ---

    台湾国内のプライバシー、反監視、オープンソースの議論の一部として活動しており、COSCUP、g0v ハッカソン、ETHTaipei、そして自分たちで開いている Internet Freedom Coffee で観測と作業を共有しています。匿名性とプライバシーに関心のある参加者と出会う場であり、作業に近い相手へ観測を戻す場でもあります。

</div>

### 継続的に追っているもの

<div class="grid cards" markdown>

- :material-wall:{ .lg .middle style="color: var(--neutral-muted);" } **中国大陸**

    ---

    一次観測ではなく公開情報を通じて追っています。Great Firewall のフィルタリングと DPI のパターン、国内プラットフォーム（WeChat、Weibo、Douyin）の実名基盤、LGBTQ+ をはじめとする声に影響するコンテンツ統制のキャンペーン、そしてこれらのシステムの国外への技術輸出に注意を払っています。2025 年の InterSecLab による Geedge と MESA の漏洩は、私たちが中国語全訳を作った唯一の地域研究です。

- :material-domain:{ .lg .middle style="color: var(--neutral-muted);" } **香港・マカオ**

    ---

    公開情報とディアスポラの人脈を通じて追っています。2020 年以降の国家安全維持法による市民空間の縮小、電子身分証 iAMSmart の拡大と HKID との統合、2023 年の終審法院による市民的結合の枠組みに関する判断、そして旅行者に対する越境時の端末検査の環境に注意を払っています。

</div>

### 状況に応じて見ているもの

<div class="grid cards" markdown>

- :material-bank-outline:{ .lg .middle style="color: var(--neutral-muted);" } **シンガポール**

    ---

    現時点ではサイト上の優先度は高くなく、シナリオが要求するときに参照します。追っている論点は、オンライン虚偽情報操作防止法（POFMA）とその発令履歴、2022 年 11 月の刑法 377A 条廃止と憲法上の婚姻定義の固定化、そして銀行、医療、行政サービスを結ぶ深く統合された実名デジタル ID の層としての Singpass です。

- :material-mosque:{ .lg .middle style="color: var(--neutral-muted);" } **マレーシア**

    ---

    現時点ではサイト上の優先度は高くなく、シナリオが要求するときに参照します。追っている論点は、連邦法の 377A / 377B 条と並行して機能する州レベルのイスラム法執行（セランゴール州の JAIS など）、LGBTQ+ の集まりを狙った摘発の反復、そしてマッチングアプリの会話や位置情報が捜査の証拠として扱われていくという報道です。

</div>

### 以上を横断するもの

<div class="grid cards" markdown>

- :material-airplane:{ .lg .middle style="color: var(--neutral-muted);" } **ディアスポラと越境**

    ---

    WeChat、LINE、WhatsApp の家族グループチャットのメタデータ、越境時の SIM と eSIM の選択、帰国時の端末の準備、そして両岸や太平洋をまたぐ亡命と移住のパターンを扱います。日本在住の読者のうち、家族や仕事のつながりが地域内にある人には直接関わる層です。

</div>

## :material-radar: どう作業しているか

地域観測には 3 本の筋があります。

**自分たちで運用する、あるいは寄与する観測。** Pulse は台湾、香港、日本、韓国の Tor リレーの分布を追跡し、このサイト上に Vega のグラフとして出しています。ASN カバレッジ分析ツールは OONI の公開データを取り込み、中国語圏の自律システムについて観測の充足度を可視化します。OONI Probe は自分たちでも動かし、OONI の方法論の更新を翻訳しています。

**追跡している規制。** 現地の法律が脅威モデルを形づくる場面では、法が実際にどう運用されているかの解説を書いています。個人資料保護法（2025 年改正）、VASP 法（2026 年）、揭弊者保護法、そして地域内の比較可能な枠組み（POFMA、国家安全維持法、377 条）への相互参照です。

**現時点で翻訳した報告書は 1 件。** 2025 年の [InterSecLab による Geedge Networks / MESA Lab 漏洩レポート](https://anoni.net/docs/reports/interseclab-network-coup/){target="_blank"}（繁体字中国語）の全訳です。これ以外に体系的な報告書ライブラリは持っておらず、今後の翻訳はその報告書が中国語圏の空白を埋めるかどうかを見て個別に判断します。

## :material-book-open-variant: 私たちが読んで引用している公開情報源

以下は地域の作業で有用だと考えている第三者の資料です。**掲載は提携や連携を意味しません。** 記録のある提携先は[私たちについて](../about/index.md)に挙げています。

- [OONI Explorer](https://explorer.ooni.org/){target="_blank"}：記録のある提携先である OONI の公開ツールです。検閲回避ツールとプラットフォームの到達性について広く使われる参照データセットで、国コードと期間で直接絞り込めます。
- [Tor Metrics](https://metrics.torproject.org/){target="_blank"}：記録のある提携先である Tor Project の公開ツールです。国別のリレー、ガード、ブリッジの数がわかり、地域の Tor の容量を把握するのに使えます。
- [Freedom House — Freedom on the Net](https://freedomhouse.org/explore-the-map){target="_blank"}：年次のスコアと詳細な国別章です。地域間比較のために引用しています。Freedom House との関係はありません。
- [Citizen Lab](https://citizenlab.ca/){target="_blank"}：トロント大学の研究グループで、アジア太平洋について実質的な成果を出しています。報告書を引用しています。関係はありません。
- [Article 19 Asia](https://www.article19.org/regions/asia/){target="_blank"} と [Access Now Asia-Pacific](https://www.accessnow.org/region/asia-pacific/){target="_blank"}：読んでいる、また推奨する地域の市民社会の視点です。いずれとも関係はありません。

## :material-handshake-outline: 一緒に作業する

アジア太平洋の中国語圏におけるネットワークの自由を取材、助成、研究していて、情報を突き合わせたい、一次観測を提供したい、あるいは共同で公開したいという場合は、[連絡先](../contact.md)に窓口をまとめています。とくに歓迎するのは次の方々です。

- 自分の法域の内側から国別の記述を鋭くできる、地域固有の寄稿者
- Pulse と ASN カバレッジの元データを公刊物で使いたい研究者
- 地域の報告書を中国語と英語のあいだで橋渡しする翻訳者
- **日本語版の訳文を校訂してくださる方**。日本語版は初稿の段階で、母語話者の校正を経ていません

## :material-information-outline: 免責

地域に関する記述は公開されている観測をまとめたものであり、法的助言ではありません。規制環境は速く動くため、個別の判断は最新の現地法と専門家に確認してください。出来事を引用する際は一次情報源にリンクします。一次情報源が中国語である場合はその旨を明記し、可能であれば信頼できる英語の要約も併せて示します。
