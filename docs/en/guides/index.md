# :material-compass-outline: Guides

Guides collects the docs site's core reading paths, from foundational concepts through specific tools and situations. Each of the three layers has its own index page, articles are grouped by topic, and the sidebar uses the same groups as the index pages.

## Three Layers { #Five-layers }

<div class="grid cards" markdown>

- [:material-school-outline: Concepts](../basics/index.md)

    The vocabulary and frameworks behind anonymity and privacy, in three groups: vocabulary and frameworks, the traces you leave, and surveillance and blocking. Start here for the shared vocabulary.

- [:material-toolbox-outline: Tools](../tools/index.md)

    Introductions and comparisons, in three groups: tools to start with, comparisons and hardening, and ways to contribute and measure regionally.

- [:material-account-group-outline: Scenarios](../scenarios/index.md)

    Practical guides for particular roles and situations. Start with the shared everyday baseline, then pick by your role, your situation, where you speak, or travel and external events such as a shutdown.

</div>

## How to Use Them { #How-to-use-them }

There is no need to read all three in order. Several ways in:

- **Your account was taken over, a device is lost, or you are being harassed**: start with [Emergency Help](../help/index.md), which covers helplines and what to do in each situation
- **You want to know what to do and can read the reasoning later**: start with [an everyday baseline](../scenarios/everyday-baseline.md), ordered by actual effect
- **You want to know how familiar you are with Tor, Tails and OONI**: place yourself on the [self-skills evaluation form](../community/skill-level.md), which links each level to a learning path
- **First time with anonymity networks**: start with [Concepts](../basics/index.md) and read through for the vocabulary and the motivation
- **Looking for a specific tool**: go straight to [Tools](../tools/index.md) for the introduction and the threat model each one addresses
- **You have a specific situation**: find the closest role in [Scenarios](../scenarios/index.md) and read the whole workflow

For regional regulation and measurement, continue to the [Regional Observatory](../regional/index.md). External research reports and guidance, with links to the English originals and our full Traditional Chinese translations, are indexed in [Translated Reports and Guidance](https://anoni.net/en/library/){target="_blank"} on the community site. The protocols and cryptography behind these tools (post-quantum cryptography, decentralized website publishing, zero-knowledge identity and more) are written up for technical readers in the community site's [Articles](https://anoni.net/en/articles/){target="_blank"}. To work with the community, see [Community](https://anoni.net/en/join/){target="_blank"}.
