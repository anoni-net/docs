# :material-flask-outline: Lab

This section holds things that are still being verified. Each page maps to one issue and exists to produce numbers that answer a single question: does this approach work?

Three things to know first:

- Pages here change often and may disappear entirely, so do not link to them from articles or from outside
- Whatever survives verification moves into the tools section and gets rewritten, so these versions are intermediate
- As in the tools section, everything runs on your device and nothing is sent to a server

## What is here now

- [Device to device transfer](webrtc-transfer.md), measuring how fast WebRTC moves files with no internet in the room, for [issue #553](https://github.com/anoni-net/docs/issues/553){target="_blank"}

## Reporting back

Every page has an export button. Attach the exported file to the issue that page maps to. IP addresses and mDNS names are masked before the file is written.

A failed attempt is still a result. Which network could not connect, which step it stopped at, and whether the message made sense are all worth recording.
