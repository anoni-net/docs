# :material-account-group-outline: 場景層

工具沒有絕對的好壞，重點是能不能對應到具體的處境與威脅。這個分類用幾個常見的角色與場景做說明，每篇文章會搭配對應的工具與設定建議，可以反向回頭看 [概念層](../basics/index.md) 與 [工具層](../tools/index.md) 補上背景知識。

找不到符合自己身分的那一篇，先看 [一般人平常該做到什麼](./everyday-baseline.md)，它是其餘各篇共用的基線，也列出什麼情況該往上走到特定場景。

!!! note "香港、澳門與其他正體中文讀者"

    本分類多數文章目前以台灣的法規與求助資源脈絡撰寫。香港、澳門讀者閱讀各篇「台灣的脈絡」一節時，請對照自身處境自行評估差異。香港在 2020 年《國安法》、2024 年《維護國家安全條例》後，社運、記者、捐款這類場景的法律風險層級遠高於台灣，台灣列出的求助管道也多半不適用。澳門的法規環境與香港不同，需另行評估。部分場景已有港澳專屬內容，見 [出差與研討會的數位準備](./asia-travel.md)。

## 目前的場景文章

- [一般人平常該做到什麼](./everyday-baseline.md)：沒有特殊身分的讀者從這篇開始。三種對手的差別、依實際效果排序的做法、被高估的做法，以及什麼時候該把標準拉高。
- [記者保護消息來源](./journalist.md)：第一次接觸、確認身分、引用層級與知情同意、不熟數位工具的來源、檔案交換、多來源之間的區隔、報導刊出後的整理，含台灣、香港與中國大陸的脈絡。
- [社運行動者的數位準備](./activist.md)：動員前準備、行動現場、行動之後、跨組織協作的逐步建議。
- [LGBTQ+ 與性少數的匿名社交](./lgbtq.md)：出櫃節奏下的帳號分層、交友 app 風險、家人控管下的本機痕跡、跨國旅行裝置準備。分層的通用設定見 [怎麼維持多個網路身分](../basics/multiple-identities.md)。
- [倡議組織的匿名捐款管道](./nonprofit-anonymous-donation.md)：給組織方與捐款人雙角色的合法匿名捐款流程，含台灣公益勸募條例、政治獻金法、VASP 與稅務脈絡。
- [在中國大陸的公開平台傳播資訊](./mainland-speech.md)：實名與網號網證之後的環境、風險落在哪些層次、有效與安全為什麼互相拉扯、跟身邊的人怎麼談，以及已經有人在承擔的存檔工作。
- [出差與研討會的數位準備（東亞與東南亞）](./asia-travel.md)：十四地的網路審查、VPN 與 Tor 可達性、SIM 實名與入境查機對照，搭配分層的行前準備清單，以及乾淨機、境外購卡與跨境攜帶的取捨。
- [出國前數位安全：用 AI 自助產生目的地概況](./travel-ai-briefing.md)：適用任何目的地，複製 prompt 問你自己的 AI，產出審查、法律、SIM、緊急聯絡的行前概況。與「東亞東南亞出差」篇互補。
- [家暴受害者的數位準備](./domestic-violence.md)：科技濫用的實際管道、怎麼在不驚動對方的前提下確認、帳號與密碼分離的順序、保全證據的方式，以及離開前後這段最高風險期該怎麼安排。
- [選舉觀察員的自保](./election-observer.md)：本地投開票所志工與跨境國際任務兩種角色的準備強度差異、現場記錄的 metadata 取捨、回報通道的設計、裝置被搜查或扣押時的應對。
