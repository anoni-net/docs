# :material-comment-alert-outline: 在新加坡與馬來西亞的網路發言

英文世界的網路言論指引多半以美國或歐洲的法律框架為前提。新加坡與馬來西亞各有一套直接管到網路言論的法規，又搭配深度整合的實名身分體系，兩種既有框架都對不上。本頁寫給人在新馬兩國、或者從當地出去的讀者，也寫給更廣的華語離散社群，適用於在政治、種族、宗教、王室、勞工、LGBTQ 這類敏感題目上發文、轉發或留言，同時想降低法律風險與被指認出身分的機會。

本頁是在地脈絡的補充，不涵蓋完整的操作流程。通用的操作安全在 [威脅模型如何建立](../basics/threat-model.md)、[社運行動者的數位準備](./activist.md) 與 [記者保護消息來源](./journalist.md)，本頁補上那幾頁預設你已經具備的新馬層次。

!!! warning "在地夥伴的查核尚未完成"

    我們透過公開資料與離散社群的聯繫追蹤新加坡與馬來西亞，沒有第一手的在地實務經驗，而兩地的法規變動很快。以下的描述請當成查找的地圖，內容以撰寫當時為準，並非法律意見。在有人依賴本頁做判斷之前，需要新加坡或馬來西亞的夥伴確認幾項現況：

    - **新加坡**：POFMA 目前的執法姿態（更正通知或刑事起訴）、FICA「政治重要人士」的認定門檻、公共秩序法對線上動員的涵蓋範圍，以及 SIM 卡實名與 Singpass 的現行細節。
    - **馬來西亞**：CMA 第 233 條在 2025 年 2 月修法後的條文與刑度、2026 年 *Heidy Quah* 案的意圖判準在實務上如何運作、煽動法目前的執法密度、社團法對「組織」的認定門檻、各州伊斯蘭法（Syariah）執法的範圍，以及 SIM 卡與 MyDigital ID 的現行要求。

    在這兩地從事組織、捐助或數位權利工作，能協助查核或共同撰寫的話，歡迎透過 [社群參與](../community/index.md) 頁面聯繫我們。

## 為什麼在地的法規框架是關鍵

同一則貼文在別的地方毫無問題，在新加坡或馬來西亞可能落進某一條具名的法條。實名身分層又讓「換個假名就好」比聽起來難做到。兩個因素構成基礎，第三個因素決定規模：

- **內容取向的言論法規**：兩國都有直接管到網路言論的法條，有些從殖民時期留下來，有些是近年新訂，執法集中在幾個敏感題目上，並未平均分布。
- **實名的底層**：新加坡的 Singpass、馬來西亞的 MyKad 與 MyDigital ID 這類國家數位身分，加上兩國都強制 SIM 卡實名，帳號、裝置與付款方式往往早就指向法律上的本名。
- **能見度與組織程度放大風險**：低觸及的貼文、爆紅的貼文、有協調的行動，三者的風險層級不同。下面記錄到的執法多半落在公眾人物、行動者與組織者身上，或者落在傳得很遠的貼文上。一般低能見度的貼文被追究的機率較低，機率低不等於安全，而且 2026 年的趨勢是起訴變多。

## 新加坡的法規環境

以下列出的是要對照檢查的法條，並未窮盡所有可能適用的法律：

- **POFMA（防止網路假訊息和網路操縱法令，2019）**：讓部長對被認定違反公共利益的網路「不實事實陳述」發出更正或下架指示。對多數發文者來說，第一個效果是更正通知或內容被移除，起訴並非常態，但情況已經改變。2026 年新加坡首度依該法提出刑事指控，一件是散布不實陳述，一件是違抗更正指示[^pofma]。無視指示本身就構成犯罪，升級的路徑確實存在。
- **FICA（防止外來干預（對應措施）法令，2021）**：賦予處理具外國連結之網路政治內容的權限，並可將特定對象認定為「政治重要人士」。實務上這類認定針對的是有組織或有外國連結的政治行為者，一般個別發文者不在其中，所以 FICA 對跨境組織者的意義大於對單一則政治留言的意義。
- **誹謗與藐視法庭**：民事與刑事誹謗，加上《司法（保護）法》的藐視法庭條款，是評論官員與進行中案件時的實際限制。
- **公開集會**：《公共秩序法》對集會的定義寬鬆，可以涵蓋線上動員，曾有室內論壇因為線上直播被認定為非法集會。

## 馬來西亞的法規環境

- **1998 年通訊與多媒體法（CMA）第 233 條**：對付網路言論最常被使用的條文。2025 年 2 月修法之後，涵蓋範圍是「猥褻、不雅、不實、具威脅性，或帶有煩擾、辱罵、威脅、騷擾意圖而**嚴重**冒犯」的內容，刑度上限也大幅提高，罰金最高 50 萬令吉（RM500,000）或兩年以下有期徒刑，涉及未成年人時更高[^cma]。有兩個限定要注意。條文管得到轉發與留言，不限於原創貼文。另一方面，2026 年聯邦法院的判決要求檢方證明真正的意圖，所以條文寫得寬不代表任何貼文都自動構成犯罪[^heidy]。
- **1948 年煽動法**：殖民時期留下來的法律，至今仍然有效且持續被使用，適用於觸及「3R」敏感議題（種族 race、宗教 religion、王室 royalty）的言論。近至 2026 年，社群媒體上談論王室的貼文仍有起訴與定罪的案例[^sedition]。
- **SOSMA（2012 年安全罪行（特別措施）法）**：為安全罪行提供特別程序，包含延長羈押。它落在最重的一端，適用對象是恐怖主義與國安犯罪，日常言論案件用不到，可以當成風險光譜的天花板，一般發文者很少碰到。
- **1966 年社團法**：以團體形式進行有協調的組織活動可能需要登記，未登記的社團本身帶有暴露面。一次性的 hashtag 不構成社團，有成員、有幹部、有持續活動的組織才可能落入其中。言論一旦變成組織行動，回頭讀 [社運行動者的數位準備](./activist.md)。
- **各州的宗教執法**：在上述法律之外，各州的伊斯蘭宗教機關執行只適用於穆斯林的 Syariah 罪行，例如被認定侮辱伊斯蘭的內容。它與煽動法的 3R 範圍是兩套不同的機制，不要當成互相重疊。

## 對你的實際意義

- **假設帳號可以連回你本人**：在前面說的實名底層之上，一般的帳號、電話號碼或付款方式往往已經指向法律上的本名，在實名帳號上換一個顯示名稱並不構成區隔。需要在沒有那層連結的情況下發言的話，區隔要從一開始就建立。
- **先確認自己碰到哪個題目，以及能見度多高**：風險集中在幾個題目上，馬來西亞是 3R，新加坡是不實陳述、外來干預與藐視法庭幾類，並隨著觸及範圍與組織程度上升。知道一則貼文碰到哪個題目、可能傳多遠，就知道哪一條法律會被引用，以及自己的暴露面有多大。
- **轉發與留言同樣算數**：馬來西亞的條文尤其管得到分享與留言，不限於自己寫的內容，「我只是轉發」的防護力比感覺上低很多。
- **人在海外不代表構不到**：新加坡的外來干預框架與 POFMA 明文主張的域外效力，加上馬來西亞條文的普遍寬度，讓跨境的政治言論值得單獨做一次威脅模型盤點。仍然會回去的話，更大的槓桿在入境時的裝置。已經在海外定居且不打算回去的話，實際的暴露面通常落在帳號層，包含內容被下架、存取被封鎖、透過在地聯絡人施壓，個人被起訴較少見，而這些法律的跨境效力目前仍在訴訟中被檢驗。

## 具體怎麼做

從 [威脅模型如何建立](../basics/threat-model.md) 開始，先確認你想避開誰的視線（國家、雇主、家人、騷擾者），以及對方現在已經看得到什麼。接著是具體的部分：

- **匿名在這裡的實際上限**：兩國都強制 SIM 卡實名，馬來西亞現在還綁上 MyDigital ID 的生物特徵驗證，Singpass 或 MyKad 又是許多服務的基礎，要取得一組真正不指向任何人的電話號碼與付款管道很困難，握有法律程序的國家行為者往往仍然能還原身分。實際的目標放在區隔與減少連結，完美匿名做不到。發言身分用另一組電子郵件、另一個瀏覽器設定檔、另一台裝置，不與本名帳號有任何接觸，兩邊不交叉發文也不交叉登入，發言帳號不綁主要門號與 Singpass 或 MyKad 相關的服務。風險高又無法真正切斷連結時，更大的槓桿常常在說什麼、傳多遠，帳號名稱反而其次。
- **選通訊軟體要看 metadata，不只看加密**：哪個 app 綁你的電話號碼、哪個不綁，在這裡比加密本身更關鍵。見 [匿名通訊工具比較](../tools/messaging-comparison.md)。
- **預先設想入境時的裝置檢查**：跨境移動是離散社群常見的暴露點，出發前先把裝置整理好。見 [出差與研討會的數位準備（東亞與東南亞）](./asia-travel.md)。
- **依處境轉到對應的場景**：處境與 LGBTQ 有關的話，[LGBTQ+ 與性少數的匿名社交](./lgbtq.md) 有新加坡與馬來西亞的細節。要保護消息來源的話，見 [記者保護消息來源](./journalist.md)。
