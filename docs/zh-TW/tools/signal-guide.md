# :material-message-lock-outline: Signal 的設定與群組管理

Signal 是開放原始碼、端對端加密的通訊 App，文字、照片、語音訊息、檔案與語音視訊通話都加密。Signal 向法院說明過，它能提供給執法機關的使用者資料只有兩項：帳號建立的時間，以及帳號最後一次連線的日期[^ssd-signal]。對話的雙方都要安裝 Signal，訊息與通話走網路，不會產生簡訊費用。

Signal 的預設已經相當安全，本頁整理裝好之後還值得調整的設定，以及經營大型群組時的做法。Signal 跟其他通訊工具的比較見 [匿名通訊工具比較](./messaging-comparison.md)，端對端加密保護得到哪裡、門號註冊與安全碼見 [端對端加密的保護範圍](../basics/e2ee.md)。

本頁依 EFF Surveillance Self-Defense 的〈How to: Use Signal〉與〈Creating and Managing Signal Groups〉兩篇合併改寫（出處見[本頁的來源與核對](#本頁的來源與核對)）。

!!! tip "時間有限的話，先看這幾點"

    - 開啟「註冊鎖」，把 Signal PIN 碼記下來，別人就無法用你的號碼在另一支手機註冊
    - 設定 username，確認「誰可以看到我的號碼」是「無人」，不想讓有你號碼的人搜到你，再把「誰可以透過電話號碼找到我」也改成「無人」
    - 敏感的對話開啟「自動銷毀訊息」，但對方仍然可以截圖
    - 經營大型群組時，先設好權限與管理員，群組連結開啟「需要管理員核准」

## 安裝與註冊

在 Google Play 或 App Store 搜尋 Signal 安裝。Signal 也有電腦版，但要先有手機上的帳號才能連結，使用電腦版時記得替電腦設定高強度的登入密碼並開啟全碟加密（見 [裝置加密與資料抹除](./device-encryption.md)）[^ssd-signal]。

註冊時的幾個選擇[^ssd-signal]：

- **通訊錄權限**：Signal 用私密的聯絡人比對機制找出通訊錄裡誰在用 Signal，上傳的資料比對完就刪除。不想分享通訊錄可以拒絕，之後要手動輸入號碼才能開始對話
- **電話號碼**：註冊需要一個可以收簡訊驗證碼的號碼。號碼預設不會顯示在個人資料上，除非對方的通訊錄本來就存了你的號碼。不想用主要的門號，可以另外準備一個號碼（門號實名制的影響見 [端對端加密的保護範圍](../basics/e2ee.md) 的〈Signal 的門號與免門號註冊〉）
- **個人資料**：名字是必填，可以用假名，照片與姓氏可以不填。名字與照片會顯示給你通訊錄裡的人、你開啟或接受對話的人，以及你加入的群組
- **Signal PIN 碼**：換手機時用來回復設定、個人資料與聯絡人，也是後面「註冊鎖」要用的那一組
- **誰可以透過電話號碼找到我**：預設是「每個人」，有你號碼的人都會在 Signal 上找到你。改成「無人」的話，要另外設定 username，對方才能開始跟你對話

## 日常使用

開新對話：在「聊天」分頁點鉛筆圖示（Android 在右下角，iPhone 在右上角），選聯絡人或輸入號碼，也可以直接發起語音或視訊通話。通話與訊息一樣是端對端加密，也可以建立「通話連結」分享給其他人加入[^ssd-signal]。

談到敏感的事情之前，可以核對對方的安全碼，確認金鑰沒有被替換：在對話中點對方的名字 >「檢視安全碼」，當面互掃 QR code 或念出數字比對，相符就點「標記為已驗證」[^ssd-signal]。安全碼變更時該怎麼判斷，見 [端對端加密的保護範圍](../basics/e2ee.md) 的〈安全碼的核對〉。

## 建議調整的設定

以下的路徑都從聊天列表左上角的個人資料圖示開始，iPhone 要先點「設定」，Android 直接進入。選單名稱依 Signal 的正體中文介面，iPhone 與 Android 偶有出入。

### 註冊鎖

開啟之後，別人沒有你的 Signal PIN 碼，就無法用你的號碼在另一支手機註冊 Signal。PIN 碼一定要記下來，換手機時忘了 PIN 碼，至少七天無法登入自己的帳號。位置在「帳號」>「註冊鎖」，還沒建立 PIN 碼的話先建立[^ssd-signal]。

### username 與電話號碼的顯示

username 的作用比較像「讓人找到你的代號」，不是社群平台那種公開帳號名稱。設定之後，跟你對話的人看不到你的號碼，除非他的通訊錄本來就存了。username 結尾至少要有兩位數字（例如 `anoni.01`），可以隨時更改，已經開始的對話不受影響，但只有舊 username 的人就找不到你了[^ssd-signal]。

- **設定 username**：點最上方你的名字 >「使用者名稱」，分享時可以產生 QR code 或連結
- **號碼的顯示**：「隱私權」>「電話號碼」，「誰可以看到我的號碼」預設是「無人」，「誰可以透過電話號碼找到我」預設是「每個人」[^ssd-signal]

### 自動銷毀訊息

訊息在對方讀取之後經過設定的時間，會從雙方的裝置上刪除，倒數從對方打開訊息開始算。擔心家人或執法人員取得手機翻看時很有用，但對方仍然可以截圖或另外記錄，這項功能防的是裝置被取得，防不了對話的另一端[^ssd-signal]。

- **新對話的預設**：「隱私權」>「自動銷毀訊息」，選擇時間
- **單一對話**：在對話中點對方或群組的名字 >「自動銷毀訊息」
- **只能看一次的照片或影片**：選好照片或影片之後，點輸入框上方的無限大符號，切換成「1」再傳送，對方一樣可以截圖[^ssd-signal]

### 通知顯示的內容

鎖定畫面的通知可能讓旁人不用解鎖就看到訊息內容，手機的 AI 通知摘要也會讀取內容。在「通知」>「顯示」選擇「只顯示名字」或「不顯示名字或內容」[^ssd-signal]。

### 備份

Signal 提供端對端加密的備份，開啟時會得到一組恢復金鑰，Signal 拿不到這組金鑰，弄丟了就無法還原備份[^ssd-signal]。

- **安全備份**：存在 Signal 的伺服器上，免費方案包含全部的文字訊息與最近 45 天的媒體，付費方案可以存到 100 GB 的媒體。每天備份一次，只能看一次的訊息與 24 小時內會自動銷毀的訊息不會備份
- **裝置上備份**：只有 Android 有，備份檔存在手機上，只能還原到同一台 Android 手機

備份是一個新的攻擊目標。曾有釣魚攻擊專門騙取 Signal 使用者的恢復金鑰，不過攻擊者光有金鑰還不夠，還要能接管帳號，所以「註冊鎖」是更重要的防線。只是擔心換手機時帶不走訊息的話，用 Signal 內建的裝置移轉也可以，但限同一種系統之間（iPhone 到 iPhone、Android 到 Android）。開了備份之後，不想被備份的對話可以設成 24 小時以內自動銷毀[^ssd-signal]。

## 高風險情況的設定

以下的設定不是每個人都需要，處境的風險比較高時再依威脅模型挑選（見 [威脅模型如何建立](../basics/threat-model.md)）[^ssd-signal]。

- **螢幕鎖定**：「隱私權」>「螢幕鎖定」，解鎖手機之後打開 Signal 還要再驗證一次
- **切換 App 時的畫面**：iPhone 在「隱私權」開啟「在應用程式切換時隱藏螢幕畫面」。Android 的對應功能是「畫面安全性功能」，開啟後也無法在自己的手機上截圖，但擋不住對方截圖
- **連結預覽**：「聊天」>「產生連結預覽」，預設關閉。開啟時網站會知道連結被分享到 Signal，帶追蹤參數的網址還可能讓人推出你在跟誰對話
- **鍵盤**：Android 在「隱私權」可以開啟無痕鍵盤，降低部分鍵盤收集輸入內容的機會，但擋不住惡意鍵盤。也順便刪掉系統設定裡不再使用的第三方鍵盤
- **通話隱藏 IP 位址**：Signal 預設用點對點通話，可能讓對方取得你的 IP 位址，不在你通訊錄裡的人來電時才會改經 Signal 的伺服器轉送。「隱私權」>「進階」開啟「永遠轉發通話」，所有通話都經伺服器轉送，代價是通話品質可能下降
- **已連結的裝置**：「已連結的裝置」列出連結到這個帳號的電腦與平板，定期檢查，看到不認得的就點旁邊的選單「解除連結」
- **限時動態**：「動態」裡可以設定誰看得到「我的限時動態」、關閉「已瀏覽標記」，或直接「關閉限時動態」
- **變更電話號碼**：換了門號，或決定改用另一個號碼時，在「帳號」>「變更電話號碼」
- **代理伺服器**：Signal 在當地被封鎖時，可以經由志工架設的代理伺服器連線，訊息仍然端對端加密，但代理伺服器的經營者看得到你的 IP 位址。設定方式與社群自架的代理伺服器見 [Signal Proxy](./signal-proxy.md)

## 群組的建立與管理

Signal 常被用在社運、互助與工會的組織工作。大型群組如果沒有人管理，很容易混亂，也容易出現過度分享、帶來法律風險的對話[^ssd-groups]。

### 技術的限制

群組裡的任何訊息都可以被截圖轉傳，有不認識的成員時，最好假設這件事會發生。端對端加密也擋不住有人取得並解鎖成員的手機[^ssd-groups]。Signal 群組最多 1,000 人，成員多到你不認識每個人（大約 50 人以上），或群組連結公開分享之後，就把它當成社群平台，假設內容可能被轉到群組以外，包括出現在警方的卷宗裡[^ssd-groups]。

### 個人資料的檢查

所有群組的成員都看得到你的名字與照片。跟不認識的人在大群組裡，可以換成不容易辨識身分的名字與照片，這件事要在加入或建立群組之前做，之後才改的話，群組的紀錄會留下變更。也順便確認「誰可以看到我的號碼」是你要的設定[^ssd-groups]。

反過來說，別人的名字與照片也是他自己取的，不一定是本名。不確定某個成員是誰時，點他的個人資料可以看到你們還同在哪些群組[^ssd-groups]。

### 成員的邀請

- **直接加入**：點群組名稱 >「新增成員」，從聯絡人加入。用號碼或 username 一個個加，比較能確定群組裡是誰
- **群組連結**：預設關閉，管理員可以在群組設定的「群組連結」開啟，連結以 `https://signal.group` 開頭。適合印在傳單或活動上廣發，風險較高的場合用只限邀請或短期的連結，活動之間「重置連結」，第一批人加入之後就關閉。開啟「需要管理員核准」，新成員要管理員同意才能加入
- **現場建群**：在「群組連結」點分享，產生 QR code 讓現場的人掃描加入

第一次對既有的群組開啟群組連結時，先告訴成員，讓大家有機會在新成員加入前檢查自己的個人資料[^ssd-groups]。

### 權限與管理員

建立群組時就決定好規則，比事後補救容易[^ssd-groups]：

- **自動銷毀訊息的時間**：建立群組時就設定。敏感的群組設成一天或一週，萬一有成員的手機被取得，裡面留下的訊息也比較少
- **權限**：點群組名稱 >「權限」，可以把「新增成員」、「編輯群組資訊」、「傳送訊息」設成「只有管理員」。全部設成只有管理員，就成了只能看公告的頻道，成員仍然可以按表情回應，討論另外開一個小群組
- **管理員**：超過幾個朋友的群組，至少指定一兩位信任的管理員。點成員的名字 >「設為管理員」。管理員要審核成員、處理衝突、移除成員、回答問題，工作量不小，先跟對方談好，也可以輪替
- **群組規則**：點群組名稱 >「新增群組描述…」，寫下群組的用途、截圖與轉傳的規範、出問題時找哪位管理員。釘選的訊息也會照自動銷毀的時間消失
- **成員標籤**：請成員在這個群組設定「成員標籤」，例如所屬的組織或地區，名字之外多一個辨識的線索

待審核的加入申請在群組設定的「要求 & 邀請」裡。Signal 不要求實名，審核新成員要自己想辦法，例如直接問對方，或請已經認識他的成員確認[^ssd-groups]。

### 成員的移除

點群組名稱 > 成員的名字 >「從群組中移除」。移除成員不會刪掉他手機上的舊訊息，改短自動銷毀的時間也不會。你自己在 24 小時內刪除自己傳的訊息，所有成員的手機上都會一起刪除。知道某位成員正在被刑事調查、或手機已經被扣押時，變更群組設定之前先諮詢律師[^ssd-groups]。

### 通知與成員辨識

- **靜音**：在聊天列表長按對話，點靜音圖示，大型群組可以先請成員這樣做
- **資料夾**：Android 可以把對話分到不同的資料夾，例如工作、家人、社區
- **暱稱**：點聯絡人的頭像 >「暱稱」，替同名或用假名的人取一個只有你看得到的名字，也可以加備註。Signal 看不到這些資料，但手機被取得時，備註可能洩漏對方的身分，風險高時備註寫得籠統一點，或乾脆不用[^ssd-groups]

社運組織的群組設計與隔離，見 [社運行動者的數位準備](../scenarios/activist.md) 的〈通訊群組的設計與隔離〉。
