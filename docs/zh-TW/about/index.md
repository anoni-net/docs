# :material-account-box-outline: 關於我們

我們是關注「**匿名網路**」、「**網路自由**」的一群人，透過 Tor、Tails、OONI 工具喚起一般大眾對網路自由的重視，並在臺灣推動隱私保護的實踐。

社群關注華語六地區（中國大陸、香港、澳門、新加坡、馬來西亞、臺灣），以及在各地之間移動的華語離散社群（diaspora）。臺灣是我們唯一能以第一手經驗發言的地方。其餘地區我們透過公開資料與當地聯絡人追蹤，凡是依據二手材料的內容都會在頁面上標明。

多數英文隱私資源以西方的威脅模型為前提，區域內的差異少有人整理。社群補上的是同一個工具在中國大陸與臺灣的行為差異、一條在地法規對威脅模型的影響，以及來自區域內部的觀測資料。

專案起初聚焦於 OONI，透過[調查](../taiwan/ooni-asn-coverage.md)臺灣 ASNs 在 OONI 資料庫中觀測資料的完整性。後來我們逐步擴展定位，進一步專注在「**匿名網路**」議題的推廣與工具建立。2025/08，我們在國立台灣科技大學順利舉辦了「[匿名網路工作坊](../event-workshop-2025.md)」，招募到第一批社群夥伴，一同展開 2026 年的工作。

**2026 年，社群聚焦三大主題**（完整規劃與各季交付見 [2026 工作藍圖](../community/roadmap-2026.md)）：

- **[個人隱私指引](../community/privacy-guide.md)**：整理可實際操作的隱私保護指引，依情境（日常、敏感工作、高風險）提供工具與步驟。
- **[Tor Relay 校園建立](../community/relay-on-campus.md)**：與 EFF、Tor Project 合作推動校園中繼節點，台師大已有一個節點運作中。社群把該案例整理成[提案範本](../community/campus-tor-relay-proposal.md)、[技術 SOP](../community/campus-tor-relay-sop.md)、[校方 FAQ](../community/campus-relay-faq.md) 三份檔案，並把臺灣專屬的內容另外標記，其他地區的推動者替換那幾段就能沿用其餘部分。
- **[匿名支付](../community/payments-research.md)**：探索現金以外情境下的匿名支付（如穩定幣、區塊鏈應用），含法規與實作面向。目前在研究階段，蒐集真實情境，也是 [Global Gathering 2026](../blog/posts/2026-anoni-net-global-gathering.md) 攤位的主題（2026/09/06，葡萄牙 Estoril）。

區域觀測的近期成果是 [2026/08/13 北部行動網路降速 30 分鐘的紀錄](../blog/posts/ooni-mobile-throttle-drill-results.md)。演練的日期、時段、縣市與電信業者都已事先公告，降速研究少有這種已知條件。文中每一則查詢都不需要 API 金鑰，任何人都能自行複驗。
