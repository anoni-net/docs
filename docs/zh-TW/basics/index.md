# :material-school-outline: 概念層

在挑選工具或學習操作之前，先把幾個關鍵概念釐清，後續閱讀工具層、場景層的內容會更順。這個分類從匿名網路社群長期關注的網路自由處境開始，再展開幾個常被混用的核心概念：「匿名」和「隱私」到底有什麼不同，威脅模型如何建立，Metadata（那些沒被加密的連線、時間、對象紀錄）為什麼會洩漏比想像中更多的資訊，社群平台實際收集了哪些東西，怎麼同時維持幾個不互相污染的網路身分，以及為什麼匿名支付是匿名實踐裡常被忽略的一塊。適合剛開始接觸匿名網路議題的讀者，先建立共同的動機與詞彙，再進入後面更具體的章節。

## 文章一覽

不確定從哪篇開始，建議先讀 [網路自由為什麼重要](./internet-freedom.md) 建立在地脈絡，再依關心的問題挑其餘八篇。

- [網路自由為什麼重要](./internet-freedom.md)：從匿名網路社群的視角看連線、個資、金流三個面向。
- [匿名、隱私、假名、機密性的差別](./anonymity-vs-privacy.md)：四個常被混用的詞，先把界線畫清楚。
- [威脅模型如何建立](./threat-model.md)：保護什麼、防誰、能付出多少成本，三個問題搭起判斷框架。
- [Metadata 是什麼，為什麼重要](./metadata.md)：通話沒被監聽，為什麼還是會被知道你聯繫了誰。
- [社群平台怎麼收集你的資料](./platform-tracking.md)：平台實際取得哪些資料、精準廣告怎麼算出來的、「手機在偷聽我說話」的感覺從哪裡來，以及中國境內平台另有的一套。
- [瀏覽器指紋是什麼，為什麼很難擺脫](./browser-fingerprinting.md)：cookie 刪得掉，指紋刪不掉，各家瀏覽器現在各自做到哪裡。
- [監控現在做得到什麼](./surveillance-capability.md)：按平台、電信、國家、商用間諜軟體四層盤點能力邊界，每一條標出證據與日期。
- [怎麼維持多個網路身分](./multiple-identities.md)：要幾層身分、每層的工具邊界、被反查的途徑，以及長期維持與收尾。
- [為什麼匿名支付重要](./payments-anonymity.md)：金流如何變成最黏的 metadata，現金為什麼是最成熟的匿名支付。
