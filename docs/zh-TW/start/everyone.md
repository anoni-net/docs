# :material-account-outline: 一般大眾從這裡開始

沒有特定的人在盯著你，只是不想被平台與廣告商過度側寫，也不想哪天帳號被盜。適用絕大多數人，也是其他幾種身分共用的基線。

下面的路徑只用站上既有的文章。二十分鐘的版本先做效果最大的幾件事，一週的版本補上背後的原理。

## 你大概正在處理的三件事

### 每個網站都要註冊，密碼重複用

一個網站外洩，同一組密碼在其他地方全部失守。多數人的第一個資安事件是這樣發生的。

[密語與密碼產生器](../utils/passphrase.md)在瀏覽器裡直接產生，不送出任何資料。

### 手機 app 一直要權限，不知道哪些該關

位置、通訊錄、相簿，多數 app 要的權限遠超過它需要的。關掉不影響使用，很多人只是沒有時間逐一檢查。

[社群平台怎麼收集你的資料](../basics/platform-tracking.md)說明收集到的東西怎麼被組合起來。

### 看到「無痕模式」、「VPN」的說法，不確定有沒有用

兩者都有用途，只是能擋的範圍比廣告詞窄很多。用錯地方會產生虛假的安全感。

[常被誤認為匿名的網路](../advanced/mistaken-for-anonymity.md)逐項說明各自實際擋掉什麼。

## 二十分鐘：先讀這三篇

1. [一般人平常該做到什麼](../scenarios/everyday-baseline.md)：做法依實際效果排序，也列出被高估的做法。整份路徑只讀一篇的話讀這篇
2. [密語與密碼產生器](../utils/passphrase.md)：投入最少、效果最直接的一項，讀完順手產生幾組
3. [常被誤認為匿名的網路](../advanced/mistaken-for-anonymity.md)：先把誤會清掉，才不會把力氣花在沒有效果的地方

## 一週：把基本功補起來

### 先做效果最大的

- [密碼管理器入門](../tools/password-manager.md)：一個網站一組密碼，靠工具而非記憶
- [郵件別名怎麼用，以及它把信任交給誰](../tools/email-alias.md)：註冊用的信箱跟主要信箱分開
- [匿名通訊工具比較](../tools/messaging-comparison.md)：日常聊天用哪一套，各自的限制在哪

### 知道正在發生什麼

- [匿名、隱私、假名、機密性的差別](../basics/anonymity-vs-privacy.md)：四個詞常被混用，混用會選錯工具
- [Metadata 是什麼，為什麼重要](../basics/metadata.md)：誰跟誰在什麼時候聯絡過，內容加密擋不住這一層
- [社群平台怎麼收集你的資料](../basics/platform-tracking.md)：你沒填的欄位是怎麼被推出來的
- [瀏覽器指紋是什麼，為什麼很難擺脫](../basics/browser-fingerprinting.md)：清 cookie 之後還剩下什麼

### 在瀏覽器裡直接用的小工具

底下三個都在你的裝置上執行，不送出任何資料。

- [你的瀏覽器透露了什麼](../utils/leaks.md)：現在就看得到自己的裝置洩漏了哪些資訊
- [網址清理器](../utils/clean-url.md)：分享連結前把追蹤參數拿掉
- [檔案 metadata 清除器](../utils/strip-metadata.md)：照片裡的座標是最常見的洩漏管道
