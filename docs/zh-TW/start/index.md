# :material-sign-direction: 從你的身分開始

站上累積了兩百多頁，第一次進來很難判斷哪幾篇跟自己有關。這一區依身分各給一條起步路徑，二十分鐘的版本先讀三篇，一週的版本再補十篇上下。開發者那條依你手上有的資源分線，結構跟其他四條不一樣。

每條路徑都指向站上既有的文章，本身不寫新的內容。想直接找某個風險的完整處理流程，到[場景](../scenarios/index.md)看，那裡按處境分篇。

## 五個入口

<div class="grid cards" markdown>

- :material-account-group:{ .lg .middle style="color: var(--brand-cyan-500);" } **公民團體**

    ---

    倡議組織、社福團體、研究型 NGO 的專職人員與志工。組織資料盤點、匿名線索管道、匿名捐款與個資法的限制。

    [:octicons-arrow-right-24: 公民團體的起步路徑](./civil-society.md)

- :material-newspaper-variant-outline:{ .lg .middle style="color: var(--cat-privacy);" } **新聞媒體**

    ---

    編輯台、法務與 IT 都在的媒體組織。公開的收件管道、素材保存與調取應對、查證時不燒掉來源。

    [:octicons-arrow-right-24: 新聞媒體的起步路徑](./media.md)

- :material-account-edit-outline:{ .lg .middle style="color: var(--cat-privacy);" } **獨立記者**

    ---

    自由撰稿人、獨立媒體的一人團隊、公民記者。同一台裝置怎麼分層、一個人怎麼收線索、出國採訪的準備。

    [:octicons-arrow-right-24: 獨立記者的起步路徑](./independent-journalist.md)

- :material-console:{ .lg .middle style="color: var(--brand-cyan-500);" } **開源科技開發者**

    ---

    會架伺服器、會寫程式、會處理資料、會寫文件的人。架設節點、觀測資料分析、校園提案、文件與翻譯，四條可以認領的線。

    [:octicons-arrow-right-24: 開發者的參與路徑](./developer.md)

- :material-account-outline:{ .lg .middle style="color: var(--cat-privacy);" } **一般大眾**

    ---

    沒有特殊處境，只是不想被平台與廣告商過度側寫。從最低成本的調整開始，也是其他四種身分共用的基線。

    [:octicons-arrow-right-24: 一般大眾的起步路徑](./everyone.md)

</div>

## 跟站上其他入口的差別

| 你想找的 | 去哪裡 |
|---|---|
| 我是誰，該從哪幾篇開始讀 | 這一區 |
| 我面對某個風險，要完整的處理流程 | [場景](../scenarios/index.md) |
| 某個工具的用途、限制與設定 | [工具](../tools/index.md) |
| 匿名、隱私、metadata 這些詞的意思 | [概念](../basics/index.md) |
| 我想加入社群一起做事 | [社群參與](../community/index.md) |
| 現在就需要找到人求助 | [緊急求救](../help/index.md) |

## 找不到你的身分

這五種身分是社群目前接觸最多的對象，涵蓋不到的處境還很多。到 [Matrix 公開 room](../community/tools.md) 說明你的狀況，會幫助我們判斷下一個入口頁要寫哪一種。有實務經驗想分享，也可以匿名寄到 [whisper@anoni.net](mailto:whisper@anoni.net)。
