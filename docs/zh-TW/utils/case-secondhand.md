# :material-tag-outline: 在二手平台賣東西

## 十四張照片準備上架

搬家日期訂了，客廳的桌子、櫃子跟一台冰箱要出清。手機拍了十四張，打算全部上架。

照片裡有你沒特別注意的東西。大門那張拍到門牌號碼。冰箱那張的背景是窗戶，對面大樓的招牌很清楚。桌子那張的桌面上躺著一張帳單，收件人姓名朝上。每一張的檔案裡還記著拍攝時的 GPS 座標、精確到秒的時間與手機型號。

平台會不會幫你拿掉拍攝資訊，各家做法不同，而且隨版本改。你自己處理過一次就不用管它們怎麼做。

## 兩個工具，多數時候只需要用一個

站上有兩個工具處理這件事，差別在處理的東西不同。

[截圖遮蔽](redact.md)處理畫面上看得見的東西。門牌、招牌、帳單上的姓名、鄰居的臉，這些在畫面裡，拿掉檔案裡的拍攝資訊對它們沒有作用。

[檔案 metadata 清除器](strip-metadata.md)處理畫面上看不見的東西。GPS 座標、拍攝時間、手機型號、編輯過的軟體名稱。

要遮的那幾張直接用截圖遮蔽就好。輸出是重新編碼的新檔案，原檔的 metadata 與檔名都不會跟過來，遮完不需要再用一次清除器。畫面上沒有東西要遮、只想拿掉拍攝資訊的那幾張，用清除器就夠。

## 遮的時候可以少拉幾個框

把圖拖進[截圖遮蔽](redact.md)之後先按「自動找出人臉」。找到的臉會用藍色空心框標出來，這時候還沒有遮住任何東西，藍框裡有不需要遮的點一下就移掉，剩下的按「全部遮起來」。

機器漏掉的自己補，在門牌或帳單姓名上按住拖出方框，放開就填成黑色。

方框填的是實心黑色，不做馬賽克也不做模糊。馬賽克把一塊區域平均成大格，模糊把像素跟周圍混在一起，兩種都保留了原本內容的統計特徵，文字尤其容易還原，針對馬賽克文字的開源還原工具 2020 年就公開了。

藍框還在的時候「產生遮好的圖」按不下去，那是刻意的。機器找到了而你還沒決定，這種狀態下交出去的圖等於一張沒遮的圖。

## 清除器會把每一段的去留列給你看

沒有東西要遮的那幾張丟進[檔案 metadata 清除器](strip-metadata.md)，照片的壓縮資料一個位元都沒有動，拿掉的是 EXIF、GPS、裝置型號那幾段，畫面本身完全沒變。處理完會逐段列出哪些留下、哪些拿掉。

## 買家要你出示證件的時候

上架之後常遇到的一種訊息是，對方說為了確認你不是詐騙，請先傳身分證或駕照的照片。

比較安全的回應是不傳。二手交易不需要任何一方出示證件，平台本身也不會要你把證件傳給另一位使用者。真的被要求提供，改用平台內建的驗證機制，讓平台去確認，你跟對方之間不交換證件影像。

已經傳出去了的話，往下看[個資外洩或被公開](../help/index.md#個資外洩或被公開Doxxing)。

## 這條路徑不只用在二手交易

任何要把照片交出去的場合都適用，先看畫面、再看檔案：

- 租屋看房拍的照片要傳給同住的人討論
- 現場活動的照片要投稿或貼上社群
- 對話截圖要交給平台檢舉或給律師看
- 給保險或維修的損壞照片

兩個工具都在你的瀏覽器裡處理，照片沒有離開裝置。頁面存進裝置之後沒有網路也能用，見[離線閱讀](../offline.md)。
