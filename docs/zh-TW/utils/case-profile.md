# :material-target-account: 廣告好像知道你在想什麼

## 準得有點過頭

上週跟朋友提過某個牌子的鞋，這幾天動態牆上一直出現它。你沒有搜尋過，也沒有點進任何一個相關的頁面。

第一個冒出來的念頭通常是手機在偷聽。偷聽的說法很直覺，也是目前為止最沒有證據的一個。實際的研究結果與把注意力放在麥克風要付的代價，都寫在[平台怎麼追蹤你](../basics/platform-tracking.md)裡。簡短的版本是，不需要麥克風也做得到，而且成本低得多。

與其猜他們有沒有在聽，不如打開頁面自己看一次他們實際上拿得到什麼。

## 打開就拿得到，不會問你

到[你的瀏覽器透露了什麼](leaks.md)。上面列的每一項，都是網站在你打開頁面的那一刻就拿得到的東西，沒有問過你，也不需要你同意。任何一個網站都拿得到同樣的東西。

清單上有作業系統、瀏覽器版本、螢幕尺寸、時區、語言、顯示卡型號、裝了哪些字型、電池狀態。單獨看每一項都不起眼，全世界跟你用同一種作業系統的人有幾億個。

## 加起來就認得出人

看最上面那個八位短碼。它是把幾項穩定的值揉在一起算出來的。

同一個瀏覽器每次打開都是同一個碼。也就是說，你不必登入、不必接受 cookie，光憑這些值就有一個跟著你走的識別碼。識別碼就是輪廓的骨架，之後你在不同網站上的行為可以串到同一個碼底下。

廣告系統要的是一個識別碼，能把「上週看過鞋子的那個人」跟「現在正在看動態牆的這個人」連起來就夠了，你的名字對它沒有用處。

## 換一個瀏覽器再看一次

換一個瀏覽器打開同一頁，看短碼有沒有變。想知道是哪一項變了，每一項下面有一行對照值，直接寫著換 Tor Browser 會顯示什麼。

用 [Tor Browser](../tools/what-is-tor.md) 打開會看到時區變成 UTC、語言變成 en-US、顯示卡變成通用字串、字型只剩固定的一組。它的做法是讓所有使用者長得一樣，網站就分不出誰是誰。這比逐項關掉功能有效，因為關掉本身也是一個特徵，關得越多反而越好認。

完整的原理見[瀏覽器指紋](../basics/browser-fingerprinting.md)。

## 連結的尾巴也帶著識別碼

輪廓的另一半在網址上。

把最近收到的任何一個連結貼進[網址清理器](clean-url.md)，它會把追蹤參數挑出來，每一個都說明是誰在追。從社群平台複製出來的連結尤其明顯，尾巴常常帶著一長串識別碼。

那串識別碼的用途是把「誰把連結給了誰」記下來。你轉發之前先清掉，不然轉出去的同時也把自己這一手接了上去。

## 清單證明不了的事

清單列出的是網站拿得到什麼。誰實際拿了、拿去做了什麼，從清單上看不出來，所以看完不等於你被追蹤，也不等於你沒有。

頁面本身不收集列出來的值，運算在你的瀏覽器裡完成，關掉頁面就沒了。

知道拿得到什麼之後可以做哪些調整，見[一般人平常該做到什麼](../scenarios/everyday-baseline.md)。內容照實際效果排序，也寫了哪些做法被高估。

## 這條路徑不只用在廣告

同一個順序適用於任何「它怎麼知道」的時刻：

- 換了一台新裝置，登入頁卻已經填著你的帳號
- 沒有登入也看得到跟你有關的推薦
- 兩個沒有互加好友的帳號被平台關聯起來
- 想知道自己在某個網站上有多容易被認出來

兩個工具都在你的瀏覽器裡執行，沒有送出任何資料。頁面存進裝置之後沒有網路也能用，見[離線閱讀](../offline.md)。
