# 研究報告中譯 { #嚴選報告 }

研究報告中譯收錄社群翻譯成正體中文的外部研究報告。收錄的報告主題跟網路審查、監控或匿名網路有關，而且對正體中文讀者有在地意義，例如報告點名了台灣的公司，或分析的審查技術來自鄰近的國家。譯文採用臺灣用語，必要時加上譯註與編輯觀察。

譯文只有正體中文版，簡體中文版與英文版的本頁列出原報告與正體中文譯文的連結。

## 已收錄的報告

### The Internet Coup / 網路政變

InterSecLab，2025-09-09。InterSecLab 分析外洩的約 500GB 檔案，說明 Geedge Networks（積至公司，積至（海南）信息技術有限公司）如何把中國防火長城的技術做成產品、部署與營運，並輸出到其他國家。

* 原報告：[The Internet Coup: A Technical Analysis on How a Chinese Company is Exporting The Great Firewall to Autocratic Regimes - InterSecLab](https://interseclab.org/research/the-internet-coup/){target="_blank"}
* 正體中文譯文（八個章節）：[網路政變](./interseclab-network-coup/index.md)

### MADLink / 台灣在 Geedge 供應鏈中的遺留

InterSecLab，2026-04-24。InterSecLab 供應鏈調查系列的第一篇，調查發現台灣上市公司凌華科技（ADLINK，股票代號 6166）在 2019 至 2020 年間出貨 1,708 台 CSA-7400 網路安全設備給 Geedge Networks，這批設備最終部署在哈薩克的國家級網路審查系統，緬甸部署的 EtherFabric 設備中也有 ADLINK 元件。

* 原報告：[MADLink: A Taiwanese Vestige in the Geedge Supply Chain - InterSecLab](https://interseclab.org/research/madlink-a-taiwanese-vestige-in-the-geedge-supply-chain/){target="_blank"}
* 正體中文譯文（五個章節）：[MADLink](./interseclab-madlink/index.md)
* 社群對台灣後續反應的觀察，2026 年 5 月的快照：[台灣對 MADLink 報告的反應，2026 年 5 月的觀察紀錄](https://anoni.net/updates/2026/05/madlink-editorial-2026-05/){target="_blank"}
