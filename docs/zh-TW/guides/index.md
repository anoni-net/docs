# :material-compass-outline: 指南

「指南」整合了文件站的核心閱讀路徑，從基礎概念走到具體工具與實際應用場景，另外收錄外部研究報告的中譯。每個層次有自己的索引頁，列出所有文章。

## 四個閱讀層次 { #五個閱讀層次 }

<div class="grid cards" markdown>

- [:material-school-outline: 概念](../basics/index.md)

    匿名與隱私的核心思考工具：詞彙釐清、威脅模型、Metadata、平台資料收集、監控能力現況、多重身分、網路自由、匿名支付、端對端加密，以及常被誤認為匿名的網路。從這裡建立共同的動機與詞彙。

- [:material-toolbox-outline: 工具](../tools/index.md)

    具體工具的介紹與比較：Tor、Tails、OONI、Tor Browser、訊息工具、密碼管理器、加密貨幣隱私光譜、AI 服務的資料風險。

- [:material-account-group-outline: 場景](../scenarios/index.md)

    特定角色或情境的應用：一般人的日常防護、記者、社運參與者、家暴倖存者、LGBTQ+ 與性少數、選舉觀察員、匿名捐款、出差與跨境、在中國大陸的公開平台發聲。

- [:material-file-pdf-box: 研究報告中譯](../reports/index.md)

    外部研究報告的完整中譯：InterSecLab 的「網路政變」與 MADLink 兩份報告。

</div>

## 如何走這條路徑

不必照順序讀完全部四個分類，幾種切入方式：

- **想先知道該做什麼，之後再讀原理**：從[一般人平常該做到什麼](../scenarios/everyday-baseline.md)開始，做法按實際效果排序
- **第一次接觸匿名網路**：從[概念](../basics/index.md)開始，依序讀完建立詞彙與動機
- **想找特定工具**：直接到[工具](../tools/index.md)找對應工具的介紹與威脅模型
- **有具體需求**：到[場景](../scenarios/index.md)找最接近自己的角色，看完整流程
- **想看外部研究**：到[研究報告中譯](../reports/index.md)讀完整的中譯

延伸到在地的法規與觀測，可以接著看[在地脈絡](../taiwan/index.md)。協定與密碼學的原理（後量子密碼、去中心化網站發布、零知識身分驗證等）寫給技術讀者，收在社群首頁的[技術文章](https://anoni.net/articles/){target="_blank"}。想加入社群協作，見[社群參與](https://anoni.net/join/){target="_blank"}。
