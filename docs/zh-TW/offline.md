# :material-wifi-off: 目前離線中

你的裝置目前沒有網路連線，而這個頁面還沒有被快取下來。

別擔心，之前瀏覽過的頁面已經存在裝置裡，回到上一頁或從首頁開始，仍然可以離線閱讀。

## 哪些內容會存在你的裝置上

你第一次用一般瀏覽器打開這個站時，目前語言的核心章節（概念、工具、進階、在地）就會在背景下載到裝置的快取裡，不需要你另外安裝任何東西。切換到其他語言時，那個語言的章節才會另外下載，所以裝置上只會有你實際讀過的語言。之後瀏覽過的頁面同樣會被存下來。

記者、行動者、LGBTQ、家暴這幾類場景頁**不在預先下載的範圍內**，只有你自己點開過才會被存下來。這些頁面留在裝置上本身可能就是敏感訊號，所以是否留存交給你決定。

你在語言選單選過的閱讀語言也存在同一個地方，站台用它決定下次從首頁進來時開哪一個語言版本，除此之外不會拿去做別的事。站台不會讀取瀏覽器回報的語言，那個值在 Tor Browser 上一律是英文，照著判斷會把台灣讀者帶去英文版。

要清掉這些內容，在瀏覽器裡清除本站的網站資料即可。Chrome 是設定的「清除瀏覽資料」勾選「Cookie 和其他網站資料」，Firefox 是「清除近期歷史」並展開細項勾選「Cookie 和網站資料」。只勾「快取的圖片和檔案」清不掉這一類儲存。

## 站上內容有新版本時

站上有新版本時，頁面頂端會出現一條提示，按下「立即更新」才會套用。這樣安排是為了避免在你閱讀的過程中把內容抽換掉。沒有按也沒關係，線上瀏覽一直都是最新內容，裝置上的離線副本則維持原樣，直到你按下更新。

## 可以試試

- 回到[首頁](index.md)瀏覽已快取的內容
- 檢查 Wi-Fi 或行動網路是否正常
- 如果你身處網路被封鎖或干擾的環境，恢復連線後可以參考[翻牆與審查規避工具](tools/index.md)

連線恢復後重新整理此頁，就會回到正常內容。
