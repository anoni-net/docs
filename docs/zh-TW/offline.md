# :material-wifi-off: 離線閱讀

如果你是因為沒有網路連線被帶到這裡，你要找的那一頁還沒有存到這台裝置上。下面的清單會列出裝置上還讀得到的頁面，標題點下去就開得起來。沒有網路時清單會自動收起沒存到的那些，只留現在讀得到的。

這一頁同時是離線內容的管理處。下面看得到裝置上目前存了什麼、可以自己挑要留哪些、也可以把它們全部清掉。趕時間的話，清單上方有一顆「全部存到裝置」，按下去就把還沒存的整批存下來，不必一章一章展開勾選。

## 把這個站裝成離線 App

不裝也能離線閱讀，用一般瀏覽器開過這個站，上面那些內容就會存下來。裝成 App 的差別在入口：有自己的圖示與視窗，斷網時直接點就進得來，不必先開瀏覽器再找書籤。

!!! tip "趁現在還連得上"
    這是預先準備。等網路斷了才裝就來不及，花一分鐘裝好，等於在裝置裡先存一份離線版指南。

用一般瀏覽器開 [anoni.net/docs](index.md)，先不要用 Tor Browser，原因見下：

- **Android（Chrome、Edge 等）**：開站後點瀏覽器選單，選「安裝應用程式」或「加到主畫面」。
- **電腦（Chrome、Edge）**：網址列右側會出現安裝圖示，或從選單選「安裝 anoni.net Docs」。
- **iPhone、iPad（Safari）**：點「分享」鈕，再選「加入主畫面」。

裝好之後長按 App 圖示，捷徑選單裡有「離線閱讀」，直接開到這一頁。

Tor Browser 以及 onion、IPFS 版基於隱私考量不提供離線安裝，那些版本不會註冊背景的 Service Worker。需要離線備援時用一般瀏覽器在 anoni.net 安裝，平時的匿名瀏覽再回到 Tor Browser。

## 哪些內容會存在你的裝置上

你第一次用一般瀏覽器打開這個站時，目前語言的核心章節（概念、工具、進階、在地）就會在背景下載到裝置的快取裡，不需要你另外安裝任何東西。切換到其他語言時，那個語言的章節才會另外下載，所以裝置上只會有你實際讀過的語言。之後瀏覽過的頁面同樣會被存下來，這一項跟核心章節一樣由上面那個開關控制，關掉之後讀過的頁面就不留在裝置上。

網站自動存的那批跟著網站版本走。網站一發布新版本，那一份會被清掉重新下載，而重新下載只涵蓋你當下開著的那個語言。要確保某些內容留在裝置上，用清單上方的「全部存到裝置」，那顆存進來的不受網站換版影響。

「全部存到裝置」一次只處理你當下所在的語言。三個語言都要帶著走的話，切到每個語言的離線閱讀頁各按一次。

記者、行動者、LGBTQ、家暴這幾類場景頁**不在預先下載的範圍內**，只有你自己點開過才會被存下來。這些頁面留在裝置上本身可能就是敏感訊號，所以是否留存交給你決定。需要離線帶著走的話，在上面的清單裡自己勾起來就會存下來。「全部存到裝置」那顆會把這幾類一併存下來，按鈕旁邊也寫著這件事，你的處境需要挑的話就用清單自己勾。

網站自動存的那批章節預設只存文字，離線打開會缺圖。上面有一個「連同核心章節的內文圖一起存」的選項，打開之後那些圖也會下載，大約多 7 MB，下次連上網時開始補。預設關著是因為多數人在行動網路上，而缺圖仍然讀得懂大部分內容。

你自己勾的頁面不受那個選項影響，一律連內文圖一起存，畫面上顯示的大小已經把圖算進去了。

你在語言選單選過的閱讀語言也存在同一個地方，網站用它決定下次從首頁進來時開哪一個語言版本，除此之外不會拿去做別的事。網站不會讀取瀏覽器回報的語言，那個值在 Tor Browser 上一律是英文，照著判斷會把台灣讀者帶去英文版。

上面的「清除所有離線內容」會把網站存的與你自己選的一起清掉，並把自動存下內容關掉，所以清完之後你讀過的頁面也不會再留在裝置上。要恢復，回到上面把開關打開即可。

這一頁本身與它需要的樣式不受那個開關管，下次連上網時會補回來（約 0.5 MB）。留著它是因為想清掉裝置上的東西、或想看還有哪些內容可讀的時候，往往正好是連不上網的時候，那時這一頁進不去的話就只剩瀏覽器的錯誤畫面。

那顆按鈕清不掉的東西：瀏覽記錄、DNS 快取，以及你從站上下載過的檔案。那些要在瀏覽器或系統設定裡處理。Chrome 是設定的「清除瀏覽資料」，Firefox 是「清除近期歷史」並展開細項勾選「Cookie 和網站資料」。只勾「快取的圖片和檔案」清不掉網站儲存這一類。

## 站上內容有新版本時

網站有新版本時，畫面底部會浮出一條提示，按下「更新」才會套用，並且會重新載入你正在看的這一頁。這樣安排是為了避免在你閱讀的過程中把內容抽換掉。沒有按也沒關係，線上瀏覽一直都是最新內容，裝置上的離線副本則維持原樣，直到你按下更新。
