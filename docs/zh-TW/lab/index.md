# :material-flask-outline: 實驗區

這一區放還在驗證中的東西。每一頁對應一則 issue，用途是量出一組數字，回答「這條路走不走得通」。

三件事先說明：

- 這裡的頁面隨時會改，也可能整個消失，不要從文章或外部連過來
- 驗證完成的東西會搬進小工具區並且重寫，這一區的版本是中間產物
- 跟小工具區一樣，運算在你的裝置上進行，沒有任何資料送到伺服器

## 現在有什麼

- [裝置之間直接傳檔](webrtc-transfer.md)，量 WebRTC 在沒有網際網路的現場能傳多快，對應 [issue #553](https://github.com/anoni-net/docs/issues/553){target="_blank"}

## 怎麼回報

每一頁都有匯出紀錄的按鈕，匯出的檔案貼回該頁對應的 issue。匯出前會把 IP 與 mDNS 名稱遮掉。

測不成功也是結果。哪一種網路連不上、在哪一步卡住、訊息看不看得懂，這些都要記下來。
