# 部落格技術文章的新位置

文件站寫給剛開始接觸匿名網路與隱私的人，讀者可能還不知道 Tor 是什麼。需要先懂 Tor、密碼學或網路量測才讀得懂的文章，這次搬到社群首頁新開的[技術文章](https://anoni.net/articles/){target="_blank"}，部落格之後只放寫給一般讀者的翻譯、分析與在地觀察。

<!-- more -->

## 搬走與調整的內容

| 內容 | 新位置 |
|---|---|
| 進階區的去中心化網站發布、後量子密碼、零知識身分驗證與支付，以及端對端加密的協定機制 | 社群首頁的[技術文章](https://anoni.net/articles/){target="_blank"} |
| 端對端加密、常被誤認為匿名的網路 | 留在文件站，移到[概念](../../basics/index.md)，端對端加密改寫成[端對端加密的保護範圍](../../basics/e2ee.md) |
| OONI Run v2 普查、8/13 行動網路降速的量測紀錄、OONI 錯誤量測與匿名憑證、無狀態 Tor Relay、Unredacted、Tor 系統管理團隊的 ADR、oniux，以及離線閱讀的技術設計 | 社群首頁的[技術文章](https://anoni.net/articles/){target="_blank"} |
| 降速演練的號召、互動區上線、兩份報告翻譯的上線公告 | 社群首頁的[社群動態](https://anoni.net/updates/){target="_blank"} |
| Arti、Tails、OONI Probe 舊版本的發布公告 | 併進[更新日誌](../../changelog/index.md) |
| 《虛擬資產服務法》行政院草案的整理 | 併進[台灣 VASP 法 2026](../../taiwan/vasp-2026.md) |

「嚴選報告」改名為[研究報告中譯](../../reports/index.md)，MADLink 報告的編輯觀察改成一篇社群動態，以 2026 年 5 月的快照保存。

## 舊網址

舊網址會自動轉到新位置，onion 版本一樣，書籤與其他文章裡的連結都還能用。這次調整的過程記錄在 [toomore/anoni-net-ws#406](https://github.com/toomore/anoni-net-ws/issues/406){target="_blank"}。
