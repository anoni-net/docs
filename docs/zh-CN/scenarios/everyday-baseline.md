# :material-account-outline: 一般人平常该做到什么

场景层其他几篇针对记者、社运参与者、家暴幸存者，这些角色有明确的对手。没有特殊身分的人同样被大量收集数据，只是对手的组成不同，该做的事也不同。

常见的做法按实际效果排序如下，每一项标出它挡掉什么、挡不掉什么。不需要照顺序做完，从第一层开始就有效果。

## 你面对的是三种不同的对手

三者的强度、发生机率与造成的损失差异很大，需要的防护也不一样。

**商业数据收集**。平台、广告商、数据掮客持续在做，不针对你个人，目的是分类与投放。推荐准确到让人不安的感觉就是从这里来的，那个感觉没有错，收集确实在发生。它造成的多半是分类与价格上的差别待遇，累积得慢也分散，对应的做法在第二层。实际机制见 [社群平台怎么收集你的数据](../basics/platform-tracking.md)。

**诈骗与账号入侵**。以自动化撒网为主，偶尔针对特定对象。实际造成金钱损失的是这一层。台湾 2025 年全年受理诈骗案件 16.2 万件，财损 893.26 亿元新台币[^165]。

**针对性调查**。具备法律程序或技术资源的对手。台湾的门槛写在《通讯保障及监察法》里，通讯监察书须由法官核发，原则上限于最轻本刑三年以上有期徒刑之罪或法条列举的特定罪名，并有期限与陈报义务。成本与程序限制让对象有限，多数人不在名单上，触发条件见 [什么时候该把标准拉高](#什么时候该把标准拉高)。

把力气全放在第三种对手上，第二种造成的损失照样会发生。反过来也一样。

!!! warning "在部分法域，第三种对手的门槛低很多"

    上面的排序假设针对性调查成本高、对象有限。在中国境内，实名制、平台的法定留存与内容审核让这个门槛降低许多，公开发言本身就可能触发。香港自 2020 年《国安法》与 2024 年《维护国家安全条例》之后，国安案件的刑度以年计，2026 年 3 月起涉国安调查时拒绝交出设备密码本身即构成犯罪。第一层与第二层的做法仍然适用，但「多数人不在名单上」这个前提要重新评估。见 [在中国大陆的公开平台传播信息](./mainland-speech.md)，以及 [出差与研讨会的数位准备](./asia-travel.md) 的香港段。

## 排序的依据

下面的顺序按两件事排：实际发生的机率乘上损失，以及一次设置能撑多久。技术强度高但很少用到的措施排在后面，不代表它没用，代表它对多数人的日常没有优先性。

判断框架的完整版见 [威胁模型如何建立](../basics/threat-model.md)，那页的〈一般用户〉范例是本页的浓缩版。

## 第一层：挡掉大部分的账号入侵与诈骗损失

这四项打的是第二种对手，也就是实际造成金钱损失的那一种。商业数据收集要到第二层才开始处理。

**先做哪个账号**：email 最优先。其他账号的密码重设信都寄到那里，主 email 被拿下等于全部被拿下。接着是网银，再来是常用的社群账号。

四件事大约一小时可以做完，用到的工具都有堪用的免费版。

### 密码管理器，每个网站不同密码

一个网站泄漏之后，攻击者会拿同一组账号密码去试其他网站。每站不同密码把连锁反应切断在第一站。

先确认自己被波及到什么程度。到 [Have I Been Pwned](https://haveibeenpwned.com/){target="_blank"} 输入 email，会列出它出现在哪几次公开泄漏事件里。查出来的数字通常比预期高，也直接说明了为什么每站不同密码排在第一位。查询需要输入 email，维运者说明不保存查询记录，介意的话可以只查最不敏感的那个信箱。

没有用过密码管理器的话，手机内建的就能开始，iOS 有独立的「密码」app，Android 走设置 → Google → 自动填入。不需要先花时间挑软件。

密码管理器还有一个常被忽略的效果，它只在域名对得上时自动填入。到了假网站它不会跳出来，沉默本身就是警告。

挡不掉的部分：你自己把密码复制粘贴到假网站。工具选择与备援策略见 [密码管理器入门](../tools/password-manager.md)。

### 两步验证，能用强的就用强的

两步验证是登录时除了密码再多过一关。强度由高到低：

- **passkey**：用手机或电脑的指纹、脸部辨识代替密码登录，密钥存在设备里并跟域名绑定
- **硬件密钥**：YubiKey 这类 USB 或 NFC 小设备，同样跟域名绑定，官方定价自 58 美元起[^yubikey]
- **TOTP app**：会定时跳出 6 位数验证码的那种，Aegis、2FAS 都是常见选择
- **短信**：收验证码短信

短信仍然比没有好，先开起来再慢慢换。它挡得掉自动化撒网，挡不掉针对你的即时转发钓鱼。

许多银行与政府服务目前只提供短信。能改的先改，改不了的不是你能决定的，背景见 [密码管理器入门](../tools/password-manager.md) 的〈在台湾与香港的补充〉。

**备援码要先存好**。开启两步验证时服务会给一组一次性的备援码，手机遗失或换机时靠它进得去。打印出来或抄下来收在实体的地方，不要只留在同一支手机里。一般人开了两步验证之后最常见的损失，是把自己锁在门外。

passkey 的普及程度值得单独说明。厂商报告常引用的数字是主流网站的支持比例，但 2026 年一份针对 Tranco 前 10 万站点的独立普查显示，整体只有 11.3% 支持，前 100 名的站点也只有 20%[^passkey-census]。有支持的站点里 75.2% 通过外部身分提供者实作、多数是 Google 的 OAuth，画面上的「用 passkey 登录」相当比例是「用 Google 账号登录」，把关联集中到同一个账号上。所以 passkey 有就开，同时保留密码管理器。

挡掉的是密码泄漏之后的直接登录。挡不掉即时转发型的钓鱼，攻击者会把你输入的验证码转到真站点。passkey 与硬件密钥因为绑定域名可以挡这一种，TOTP 与短信不行。

### 系统与浏览器保持更新

多数被实际利用的漏洞都已经有修补，攻击者针对的是还没更新的设备。把自动更新打开，比记得定期手动检查可靠。iPhone 走设置 → 通用 → 软件更新 → 自动更新，Android 走设置 → 系统 → 系统更新，各家界面名称略有差异。

挡不掉零日漏洞，也就是修补还没出现就被利用的漏洞。零日的取得成本高，通常留给特定目标。

### 对「现在就要处理」的消息，换一个管道确认

第一层里唯一一项属于习惯而非设置。急迫感是各种诈骗共通的手法，先制造冲突，再要求你在情绪里做决定。

收到银行、物流、客服、政府机关的通知时，不要点消息里的链接，改成自己打开 app 或拨打你原本就知道的号码。多花两分钟，挡掉的比前三项加起来还多。

这一项打的是诈骗那一条线，跟前三项挡的东西不同类，两边不能互相替代。

挡不掉你自己搜索后点进去的假网站，例如在搜索引擎的广告位置点到假客服。要找官方管道时，直接输入网址或用书签。

## 第二层：值得花时间

这一层开始处理第一种对手，也就是让推荐准得可疑的那一层。

### 手机权限与广告标识符

关掉广告标识符、通讯录上传、精确位置，逐项检查权限清单。iPhone 走设置 → 隐私与安全性 → 跟踪，Android 12 起可以直接删除广告 ID。完整步骤与各级挡不掉什么，见 [社群平台怎么收集你的数据](../basics/platform-tracking.md) 的〈你能做什么〉。

那页的三级只处理平台这一条线，它的低成本大致落在本页第二层，高成本对应本页第三层，两套阶梯的层数对不起来是正常的。

挡不掉平台内部的行为讯号，也挡不掉别人上传通讯录时把你带进去。

### 全盘加密与开机密码

挡的是手机或笔电遗失、被偷之后，别人把存储设备拆出来读。iPhone 设好开机密码就是开启状态，Android 走设置 → 安全性可以确认。

挡不掉当场要求你解锁的情境，那是另一个问题，见 [出差与研讨会的数位准备](./asia-travel.md)。

### 日常通讯改用端对端加密

Signal 这类工具保护的是内容，不保护「谁在什么时候联系谁」。工具比较见 [匿名通讯工具比较](../tools/messaging-comparison.md)，为什么 metadata 常常比内容更能定义你，见 [Metadata 是什么](../basics/metadata.md)。

### 备份

勒索软件、硬盘故障、手机掉进水里，备份是本页唯一能事后救回数据的措施。重要数据至少两份，其中一份不要跟原始数据连在同一台设备或同一个账号上。

挡不掉已经外流出去的数据，备份处理的是失去，不是泄漏。

### 账号盘点

久未使用的账号是常见的泄漏来源，你也不会注意到它被入侵。用密码管理器列出所有账号，用不到的直接删除，比改密码有效。顺序与做法见 [怎么维持多个网络身分](../basics/multiple-identities.md) 的〈身分退场〉。

挡不掉对方已经拿走的旧数据，删除账号停止的是往后的累积。

## 第三层：特定情境才需要

第一层与第二层都做到之后，日常的暴露面已经处理掉大部分。剩下的是平台内部的行为讯号、它的历史记录，以及你自愿交出去的内容，换工具挡不掉。

这一层跟 [社群平台怎么收集你的数据](../basics/platform-tracking.md) 的〈高成本，特定情境才需要〉是同一组做法，账号分层、设备分开、连线层匿名，差别在触发的理由。什么时候该往上走，见下方的 [什么时候该把标准拉高](#什么时候该把标准拉高)。

## 被高估的做法

下面几项各自有明确的用途，只是常被误当成防护主力。

| 做法 | 实际效果 |
|---|---|
| VPN | 换掉谁看得到你的连线。选择标准与所有权问题见 [VPN 的风险与选择](../tools/vpn-guide.md) |
| 无痕模式 | 清掉本机记录，平台、ISP、你登录的服务照样认得你 |
| 换手机号码 | 旧号码会被运营商回收再配发给下一个人，绑在旧号码上的账号要先解绑 |
| 贴镜头贴纸 | 挡镜头很有效，但多数人担心的是麦克风。麦克风的实证见 [社群平台怎么收集你的数据](../basics/platform-tracking.md) 的〈「手机在偷听我说话」成不成立〉 |
| 删掉 app | 停止的是往后的收集，已经给出去的数据不会消失。要真的减少，先用数据导出看清楚有什么，再走删除账号流程 |

## 一年一次的检查

不需要重做一遍，逐题确认即可。

- 密码管理器里有没有重复使用的密码，工具多半内建检查功能
- 两步验证还停在短信的重要账号，有没有可以升级的
- 备援码还找得到吗，换过手机之后尤其要确认
- 一年没登录的账号，删掉
- 手机权限清单，新装的 app 要了什么
- 备份还原得回来吗？没有试过还原的备份不算备份
- 换工作、换伴侣、换城市之后，上面的假设还成立吗

## 台湾的脉络与你所在地的对应

本站以台湾的法规与求助资源为主要脉络，以下几项供对照。

- **反诈骗专线 `165`**：查证可疑消息、通报受骗。[165 打诈仪表板](https://165dashboard.tw/){target="_blank"} 公开各类型的受理件数与财损趋势，可以拿来对照当下最常见的手法
- **金融账户的警示与圈存**：受骗后第一时间可透过 `165` 或开户行办理，时间差直接影响能不能拦下款项
- **个人资料保护法**：2025 年 10 月三读、11 月公布的修正见 [台湾个资法 2025 修法](../taiwan/pdpa-2025.md)

类别可以移植，机构不行。不在台湾的读者，下面三件事值得在需要之前先查清楚。

- 你所在地的反诈骗报案专线，以及它有没有公开统计可以对照当下常见的手法
- 你所在地的个人资料主管机关，以及它能不能真的受理一件申诉
- 你的银行能多快冻结一笔已经转出去的款项，因为诈骗的可挽回程度几乎只取决于这个时间差

中国境内与港澳的法律环境差异，见上方的警告框与 [在中国大陆的公开平台传播信息](./mainland-speech.md)。

## 什么时候该把标准拉高

已经出事的情况不适用下表，账号被盗、设备遗失、遭到跟踪骚扰请直接看 [紧急求救](../help/index.md)。

上面的基线假设你没有特定对手。下列情况出现时，威胁模型变了，该读对应的那一页。

| 情况 | 往哪里走 |
|---|---|
| 开始接触敏感题材，或有人愿意向你提供内部信息 | [记者保护消息来源](./journalist.md) |
| 参与组织性行动、进出集会现场 | [社运行动者的数位准备](./activist.md) |
| 伴侣或家人有控制行为，查看你的设备与位置 | [家暴受害者的数位准备](./domestic-violence.md) |
| 出柜节奏需要控制，或在家人监看下使用网络 | [LGBTQ+ 与性少数的匿名社交](./lgbtq.md) |
| 担任选举观察员，或到投开票所记录 | [选举观察员的自保](./election-observer.md) |
| 要匿名捐款，或替组织设计捐款管道 | [倡议组织的匿名捐款管道](./nonprofit-anonymous-donation.md) |
| 要前往中国大陆、香港、缅甸这类地区 | [出差与研讨会的数位准备](./asia-travel.md)、[出国前数位安全](./travel-ai-briefing.md) |
| 要在中国境内平台公开发言 | [在中国大陆的公开平台传播信息](./mainland-speech.md) |
