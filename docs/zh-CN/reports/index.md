# 研究报告中译 { #严选报告 }

研究报告中译收录社区翻译成正体中文的外部研究报告。收录的报告主题跟网络审查、监控或匿名网络有关，而且对正体中文读者有在地意义，例如报告点名了台湾的公司，或分析的审查技术来自邻近的国家。译文采用台湾用语，必要时加上译注与编辑观察。

!!! info "报告中译版仅在 zh-TW 维护"

    研究报告中译的译文目前只在**正体中文（zh-TW）**版本维护，简体中文版暂不另做一份翻译。建议海外华语读者直接到[正体中文版的研究报告中译](https://anoni.net/docs/reports/){target="_blank"}阅读完整内容。

    长文报告的简繁差异多半在地名、技术术语用词，不影响阅读。如果未来社区人力允许，会考虑补 zh-CN 版本，但不在 2026 路线图内。

## 已收录的报告 { #已收录报告 }

### The Internet Coup / 网络政变

InterSecLab，2025-09-09。InterSecLab 分析泄漏的约 500GB 文件，说明 Geedge Networks（积至公司，积至（海南）信息技术有限公司）如何把中国防火长城的技术做成产品、部署与运营，并输出到其他国家。

* 原报告：[The Internet Coup: A Technical Analysis on How a Chinese Company is Exporting The Great Firewall to Autocratic Regimes - InterSecLab](https://interseclab.org/research/the-internet-coup/){target="_blank"}
* 正体中文译文（八个章节）：[网络政变](https://anoni.net/docs/reports/interseclab-network-coup/){target="_blank"}

### MADLink / 台湾在 Geedge 供应链中的遗留

InterSecLab，2026-04-24。InterSecLab 供应链调查系列的第一篇，调查发现台湾上市公司凌华科技（ADLINK，股票代号 6166）在 2019 至 2020 年间向 Geedge Networks 出货 1,708 台 CSA-7400 网络安全设备，这批设备最终部署在哈萨克斯坦的国家级网络审查系统，缅甸部署的 EtherFabric 设备中也有 ADLINK 元件。

* 原报告：[MADLink: A Taiwanese Vestige in the Geedge Supply Chain - InterSecLab](https://interseclab.org/research/madlink-a-taiwanese-vestige-in-the-geedge-supply-chain/){target="_blank"}
* 正体中文译文（五个章节）：[MADLink](https://anoni.net/docs/reports/interseclab-madlink/){target="_blank"}
* 社区对台湾后续反应的观察，2026 年 5 月的快照：[台湾对 MADLink 报告的反应，2026 年 5 月的观察记录](https://anoni.net/zh-cn/updates/2026/05/madlink-editorial-2026-05/){target="_blank"}
