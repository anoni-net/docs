# :material-account-outline: 一般大众从这里开始

没有特定的人在盯着你，只是不想被平台与广告商过度侧写，也不想哪天账号被盗。适用绝大多数人，也是其他几种身分共用的基线。

下面的路径只用站上既有的文章。二十分钟的版本先做效果最大的几件事，一周的版本补上背后的原理。

## 你大概正在处理的三件事

### 每个网站都要注册，密码重复用

一个网站外泄，同一组密码在其他地方全部失守。多数人的第一个安全事件是这样发生的。

[密语与密码生成器](../utils/passphrase.md)在浏览器里直接生成，不送出任何数据。

### 手机 app 一直要权限，不知道哪些该关

位置、通讯录、相册，多数 app 要的权限远超过它需要的。关掉不影响使用，很多人只是没有时间逐一检查。

[社群平台怎么收集你的数据](../basics/platform-tracking.md)说明收集到的东西怎么被组合起来。

### 看到「隐私浏览窗口」、「VPN」的说法，不确定有没有用

两者都有用途，只是能挡的范围比广告词窄很多。用错地方会产生虚假的安全感。

[常被误认为匿名的网络](../advanced/mistaken-for-anonymity.md)逐项说明各自实际挡掉什么。
