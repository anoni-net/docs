# :material-account-edit-outline: 独立记者从这里开始

适用自由撰稿人、独立媒体的一人团队、公民记者。面对的威胁跟大型媒体的记者相同，可以投入的成本与能仰赖的支援差很多，所以优先顺序需要重排。

有编辑台、法务与 IT 的组织，看[新闻媒体的起步路径](./media.md)。下面每一条连结都指向站上既有的文章。

## 你大概正在处理的三件事

### 一台手机与一台笔记本，承载采访与生活的全部

同一支手机联络来源、联络家人、登录银行。设备遗失或被查扣时，失去的东西是整批的，来源的联络记录也在里面。

先看[怎么维持多个网络身分](../basics/multiple-identities.md)，分层的通用做法都在那一篇。

### 没有机构邮箱，来源只能从个人社交账号找到你

对方在你的公开账号私信，消息内容与双方的关联都留在平台上。你需要一条能公开贴出来、对方自己就能评估风险的通道。

看[公开的安全收件管道](../scenarios/journalist.md#公开的安全收件管道)，一个人也做得起来。

### 出国采访，设备要过海关

入境查验设备在部分地区是常态，解锁与否都有代价。里面若有来源的联络记录，风险由对方承担。

看[出差与研讨会的数字准备](../scenarios/asia-travel.md)，十四地逐一整理。

## 二十分钟：先读这三篇

1. [记者保护消息来源](../scenarios/journalist.md)：从第一次接触到报导刊出的完整流程，先通读一次建立全貌
2. [威胁模型清单](../utils/threat-model.md)：三题答完会标出答案里的错配，例如对手填到国家级、成本却填最低。填的内容留在浏览器分页里，重新整理就没了
3. [怎么维持多个网络身分](../basics/multiple-identities.md)：一个人要撑起多重身分，靠的是规则而非工具

## 一周：把基本功补起来

### 把工作与生活分开

- [邮件别名怎么用，以及它把信任交给谁](../tools/email-alias.md)：注册用的邮箱与采访用的邮箱分开，成本很低
- [密码管理器入门](../tools/password-manager.md)：分层之后账号会变多，人脑记不住
- [密语与密码生成器](../utils/passphrase.md)：在浏览器里生成，不送出任何数据
- [匿名通讯工具比较](../tools/messaging-comparison.md)：跟来源联络走哪一套

### 一个人也做得到的几件事

- [什么是 Tor](../tools/what-is-tor.md)：查资料时不让对方看到你在查
- [OnionShare](../tools/onionshare.md)：来源不用注册账号就能传文件给你，不需要架服务器
- [什么是 Tails](../tools/what-is-tails.md)：处理特别敏感的素材时，换一个干净的操作环境
- [文件 metadata 清除器](../utils/strip-metadata.md)：发稿前清掉照片与文档里的座标与设备信息

### 出门采访

- [出差与研讨会的数字准备](../scenarios/asia-travel.md)：东亚与东南亚十四地的审查、SIM 实名与入境查机对照
- [出国前数字安全：用 AI 自助产生目的地概况](../scenarios/travel-ai-briefing.md)：目的地不在上一篇的清单里时，复制 prompt 自己产生一份

### 三地的法规脉络

- [法规与通讯记录](../scenarios/journalist.md#法规与通讯记录)：台湾调取的门槛与实务
- [香港的脉络](../scenarios/journalist.md#香港的脉络)：2020 年《国安法》之后的差异
- [中国大陆的脉络](../scenarios/journalist.md#中国大陆的脉络)：风险最重的一端在境内协作者身上

## 带得走的东西

- 威胁模型清单答完按「复制摘要」，贴到你自己选的地方，换题目时回头再填一次
- [隐形字符检测](../utils/invisible.md)：取得文件先扫一次，隐形标记是常见的追人手法
- [沟通与协作工具](../community/tools.md)的 Matrix、CryptPad 与 Send 都开放使用，一人团队不必自己架
- 有问题到 [Matrix 公开 room](../community/tools.md) 问，需要传敏感文件寄 [whisper@anoni.net](mailto:whisper@anoni.net)

## 这条路径没有处理的

- **机构层级的素材保存与调取应对**：见[新闻媒体的起步路径](./media.md)
- **已经发生的安全事件**：先看[紧急求救](../help/index.md)
- **在中国大陆工作的记者**：处境与上面的假设差距最大，[在中国大陆的公开平台传播信息](../scenarios/mainland-speech.md)贴近得多，建议先读那一篇
