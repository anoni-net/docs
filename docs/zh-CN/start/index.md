# :material-sign-direction: 从你的身分开始

站上累积了两百多页，第一次进来很难判断哪几篇跟自己有关。这一区依身分各给一条起步路径，二十分钟的版本先读三篇，一周的版本再补十篇上下。开发者那条依你手上有的资源分线，结构跟其他四条不一样。

每条路径都指向站上既有的文章，本身不写新的内容。想直接找某个风险的完整处理流程，到[场景](../scenarios/index.md)看，那里按处境分篇。

## 五个入口

<div class="grid cards" markdown>

- :material-account-group:{ .lg .middle style="color: var(--brand-cyan-500);" } **公民团体**

    ---

    倡议组织、社福团体、研究型 NGO 的专职人员与志愿者。组织数据盘点、匿名线索渠道、匿名捐款与个人信息保护的限制。

    [:octicons-arrow-right-24: 公民团体的起步路径](./civil-society.md)

- :material-newspaper-variant-outline:{ .lg .middle style="color: var(--cat-privacy);" } **新闻媒体**

    ---

    编辑台、法务与 IT 都在的媒体组织。公开的收件渠道、素材保存与调取应对、查证时不烧掉来源。

    [:octicons-arrow-right-24: 新闻媒体的起步路径](./media.md)

- :material-account-edit-outline:{ .lg .middle style="color: var(--cat-privacy);" } **独立记者**

    ---

    自由撰稿人、独立媒体的一人团队、公民记者。同一台设备怎么分层、一个人怎么收线索、出国采访的准备。

    [:octicons-arrow-right-24: 独立记者的起步路径](./independent-journalist.md)

- :material-console:{ .lg .middle style="color: var(--brand-cyan-500);" } **开源科技开发者**

    ---

    会架服务器、会写程序、会处理数据、会写文档的人。架设节点、观测数据分析、校园提案、文档与翻译，四条可以认领的线。

    [:octicons-arrow-right-24: 开发者的参与路径](./developer.md)

- :material-account-outline:{ .lg .middle style="color: var(--cat-privacy);" } **一般大众**

    ---

    没有特殊处境，只是不想被平台与广告商过度侧写。从最低成本的调整开始，也是其他四种身分共用的基线。

    [:octicons-arrow-right-24: 一般大众的起步路径](./everyone.md)

</div>

## 跟站上其他入口的差别

| 你想找的 | 去哪里 |
|---|---|
| 我是谁，该从哪几篇开始读 | 这一区 |
| 我面对某个风险，要完整的处理流程 | [场景](../scenarios/index.md) |
| 某个工具的用途、限制与设置 | [工具](../tools/index.md) |
| 匿名、隐私、metadata 这些词的意思 | [概念](../basics/index.md) |
| 我想加入社群一起做事 | [社群参与](../community/index.md) |
| 现在就需要找到人求助 | [紧急求救](../help/index.md) |

## 地区差异请自行评估

下面五页的法规段落多数以台湾脉络撰写，社群的直接经验也在台湾。中国大陆、香港、澳门读者阅读时请对照自身处境重新评估，风险层级与可用的求助渠道差距很大。

在中国大陆的读者，[在中国大陆的公开平台传播信息](../scenarios/mainland-speech.md)写的是实名与网号网证之后的环境，比五个身分入口更贴近你的处境，建议先读那一篇。

## 找不到你的身分

这五种身分是社群目前接触最多的对象，涵盖不到的处境还很多。到 [Matrix 公开 room](../community/tools.md) 说明你的状况，会帮助我们判断下一个入口页要写哪一种。有实务经验想分享，也可以匿名寄到 [whisper@anoni.net](mailto:whisper@anoni.net)。
