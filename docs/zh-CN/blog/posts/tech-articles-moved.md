# 博客技术文章的新位置

文档站写给刚开始接触匿名网络与隐私的人，读者可能还不知道 Tor 是什么。需要先懂 Tor、密码学或网络测量才读得懂的文章，这次搬到社区首页新开的[技术文章](https://anoni.net/zh-cn/articles/){target="_blank"}，博客之后只放写给一般读者的翻译、分析与在地观察。
