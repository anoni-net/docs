# :material-target-account: 广告好像知道你在想什么

## 准得有点过头

上周跟朋友提过某个牌子的鞋，这几天信息流上一直出现它。你没有搜索过，也没有点进任何一个相关的页面。

第一个冒出来的念头通常是手机在偷听。那个解释很直觉，也是目前为止最没有证据的一个。[平台怎么追踪你](../basics/platform-tracking.md)那一篇整理了实际的研究结果，以及把注意力放在麦克风要付的代价。简短的版本是，不需要麦克风也做得到，而且成本低得多。

这一篇要做的是另一件事。与其猜他们有没有在听，不如打开页面自己看一次他们实际上拿得到什么。

## 打开就拿得到，不会问你

到[你的浏览器透露了什么](leaks.md)。上面列的每一项，都是网站在你打开页面的那一刻就拿得到的东西，没有问过你，也不需要你同意。任何一个网站都拿得到同样的东西。

清单上有操作系统、浏览器版本、屏幕尺寸、时区、语言、显卡型号、装了哪些字体、电池状态。单独看每一项都不起眼，全世界跟你用同一种操作系统的人有几亿个。

## 加起来就认得出人

看最上面那个八位短码。它是把几项稳定的值揉在一起算出来的。

同一个浏览器每次打开都是同一个码。也就是说，你不必登录、不必接受 cookie，光凭这些值就有一个跟着你走的标识码。这就是轮廓的骨架，之后你在不同网站上的行为可以串到同一个码底下。

广告系统要的是一个标识码，能把「上周看过鞋子的那个人」跟「现在正在看信息流的这个人」连起来就够了，你的名字对它没有用处。

## 换一个浏览器再看一次

这一页最有用的用法是比较。

换一个浏览器打开同一页，看短码有没有变。想知道是哪一项变了，每一项下面有一行对照值，直接写着换 Tor Browser 会显示什么。

用 [Tor Browser](../tools/what-is-tor.md) 打开会看到时区变成 UTC、语言变成 en-US、显卡变成通用字符串、字体只剩固定的一组。它的做法是让所有用户长得一样，网站就分不出谁是谁。这比逐项关掉功能有效，因为关掉本身也是一个特征，关得越多反而越好认。

完整的原理见[浏览器指纹](../basics/browser-fingerprinting.md)。

## 链接的尾巴也带着标识码

轮廓的另一半在网址上。

把最近收到的任何一个链接粘贴进[网址清理器](clean-url.md)，它会把跟踪参数挑出来，每一个都说明是谁在跟踪。从社交平台复制出来的链接尤其明显，尾巴常常带着一长串标识码。

那串东西的用途是把「谁把这个链接给了谁」记下来。你转发之前先清掉，不然转出去的同时也把自己这一手接了上去。

## 这一页不能证明的事

清单列出的是网站拿得到什么，不是谁实际拿了、拿去做了什么。看完不等于你被追踪，也不等于你没有。

站上那一页本身不收集列出来的值，运算在你的浏览器里完成，关掉页面就没了。

知道拿得到什么之后可以做哪些调整，见[一般人平常该做到什么](../scenarios/everyday-baseline.md)。那一篇照实际效果排序，也写了哪些做法被高估。

## 这条路径不只用在广告

同一个顺序适用于任何「它怎么知道」的时刻：

- 换了一台新设备，登录页却说认得你
- 没有登录也看得到跟你有关的推荐
- 两个没有互加好友的账号被平台关联起来
- 想知道自己在某个网站上有多容易被认出来

两个工具都在你的浏览器里执行，没有发出任何数据。页面存进设备之后没有网络也能用，见[离线阅读](../offline.md)。
