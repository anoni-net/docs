# :material-tag-outline: 在二手平台卖东西

## 十四张照片准备上架

搬家日期定了，客厅的桌子、柜子跟一台冰箱要出清。手机拍了十四张，打算全部上架。

照片里有你没特别注意的东西。大门那张拍到门牌号码。冰箱那张的背景是窗户，对面大楼的招牌很清楚。桌子那张的桌面上躺着一张账单，收件人姓名朝上。每一张的文件里还记着拍摄时的 GPS 坐标、精确到秒的时间与手机型号。

平台会不会帮你去掉拍摄信息，各家做法不同，而且随版本改。你自己处理过一次就不用管它们怎么做。

## 两个工具，多数时候只需要用一个

站上有两个工具处理这件事，差别在处理的东西不同。

[截图遮蔽](redact.md)处理画面上看得见的东西。门牌、招牌、账单上的姓名、邻居的脸，这些在画面里，去掉文件里的拍摄信息对它们没有作用。

[文件 metadata 清除器](strip-metadata.md)处理画面上看不见的东西。GPS 坐标、拍摄时间、手机型号、编辑过的软件名称。

要遮的那几张直接用截图遮蔽就好。输出是重新编码的新文件，原文件的 metadata 与文件名都不会跟过来，遮完不需要再用一次清除器。画面上没有东西要遮、只想去掉拍摄信息的那几张，用清除器就够。

## 遮的时候可以少拉几个框

把图拖进[截图遮蔽](redact.md)之后先按「自动找出人脸」。找到的脸会用蓝色空心框标出来，这时候还没有遮住任何东西，蓝框里有不需要遮的点一下就移掉，剩下的按「全部遮起来」。

机器漏掉的自己补，在门牌或账单姓名上按住拖出方框，放开就填成黑色。

方框填的是实心黑色，不做马赛克也不做模糊。马赛克把一块区域平均成大格，模糊把像素跟周围混在一起，两种都保留了原本内容的统计特征，文字尤其容易还原，针对马赛克文字的开源还原工具 2020 年就公开了。

蓝框还在的时候「生成遮好的图」按不下去，那是刻意的。机器找到了而你还没决定，这种状态下交出去的图等于一张没遮的图。

## 清除器会把每一段的去留列给你看

没有东西要遮的那几张丢进[文件 metadata 清除器](strip-metadata.md)，照片的压缩数据一个位都没有动，去掉的是 EXIF、GPS、设备型号那几段，画面本身完全没变。处理完会逐段列出哪些留下、哪些去掉。

## 买家要你出示证件的时候

上架之后常遇到的一种消息是，对方说为了确认你不是诈骗，请先发身份证或驾照的照片。

比较安全的回应是不发。二手交易不需要任何一方出示证件，平台本身也不会要你把证件发给另一位用户。真的被要求提供，改用平台内置的验证机制，让平台去确认，你跟对方之间不交换证件影像。

已经发出去了的话，往下看[个资外泄或被公开](../help/index.md#个资外泄或被公开Doxxing)。

## 这条路径不只用在二手交易

任何要把照片交出去的场合都适用，先看画面、再看文件：

- 租房看房拍的照片要发给同住的人讨论
- 现场活动的照片要投稿或发上社交平台
- 对话截图要交给平台举报或给律师看
- 给保险或维修的损坏照片

两个工具都在你的浏览器里处理，照片没有离开设备。页面存进设备之后没有网络也能用，见[离线阅读](../offline.md)。
