## 什么时候用得上

[Metadata 是什么](../basics/metadata.md)那篇提到，照片里带着拍摄时间、相机型号与 GPS 坐标，而「上传照片前先去 EXIF」是任何人现在就能做的低成本防护。

问题在于怎么去。线上的清除工具几乎都要先把文件传上去，而会需要清 metadata 的人，正是最不该把原始文件交出去的人。

这一页在你的浏览器里改，文件不离开设备。清完的是新的一份，原始文件不会被动到。

两种常见的处境：

- **刚搬到新住处，想传一张照片给朋友报平安。** 手机拍照默认会把 GPS 坐标写进文件里。朋友看到的是一张照片，有心找的人看到的是一组坐标。传出去之前清一次，画面完全不受影响。
- **在现场拍了画面要投稿给媒体。** 照片里的拍摄时间与坐标合起来，指得出是谁在什么时候站在哪里。清掉之后编辑台收到的还是同一张图。

## 拿掉什么，留下什么

照片文件里，图像本身跟描述用的字段是分开存放的。这一页把描述那几段整段拿掉，图像那部分一个比特都不碰。

| 拿掉 | 里面是什么 |
|---|---|
| EXIF | 拍摄时间、相机型号、GPS 坐标，还有一张没被裁切过的缩略图 |
| XMP | Adobe 系列软件写的描述，常含地点与作者 |
| IPTC 与 Photoshop 字段 | 说明、作者、关键词 |
| 注释字段 | 文件里夹带的任意文字 |
| 修改时间 | 上次存档的时间 |

| 留着 | 为什么 |
|---|---|
| 色彩描述文件 | 拿掉的话颜色会偏掉。这种描述文件多半是 sRGB 这类标准的，识别力低 |
| 色彩转换标记 | 印刷用的 CMYK 文件少了它，颜色会反过来 |
| 基本兼容信息 | 少了它有些看图程序会抱怨 |
| 图像本身 | 拿掉就解不开或变样 |

那张没被裁切过的缩略图值得单独提。你把照片裁掉一半再传出去，EXIF 里那张缩略图可能还是原本的完整画面。

画面上会逐项列出这次拿掉与留下的东西，含各自占几个比特组，还有文件格式里对应的段落代号。工具不替你决定去留，看得到才算数。

## 视频是一样的道理

MP4 与 MOV 也在处理范围里。手机拍的视频跟照片一样会记录拍摄地点、设备型号与时间，而且视频通常更难察觉，因为多数人不会去看视频的属性。

这种文件是一层包一层的结构，描述字段住在其中一层。整段拿掉不需要碰压缩过的音视频数据，跟照片是同一种做法，清完的视频解码出来跟原文件一个比特都不差。

三个地方会被清掉：

- 用户数据区：标题、作者、拍摄地点坐标、设备型号
- 编码器名称与版本：那会指出你用什么软件或哪一款手机处理过
- 轨道的处理器名称：不同平台写法不同，等于一个平台指纹

### 有一种痕迹清不掉

编码器会把自己的版本写进压缩数据本身。那一段不是描述字段，是音视频数据的一部分，位置跟画面内容混在一起。

要清掉只能重新编码，而重新编码会损失画质，也只是把旧编码器的痕迹换成新的。这一页不做那件事，但会把扫到的字符串列出来告诉你，不让你以为清干净了。

## 清完的图跟原图完全一样

这一页不重新编码。图像与音视频数据从文件里的固定位置开始照抄，一个比特都没动。

重新编码的工具做不到无损。每一次重新压缩都会损失画质，而且会在输出里留下自己的处理痕迹，那本身又变成一种可辨识的特征。用 mat2 清过的文件看得出来是 mat2 清的。

也因为是无损的，清完之后文件通常只小一点点。一张 630 KB 的照片清掉完整的 EXIF 之后是 629 KB，那 140 个比特组就是原本记着相机型号与坐标的地方。

## 不支持的格式

**HEIC/HEIF**：iPhone 默认拍出来就是这个格式，它的容器结构复杂得多，这一页还做不到。在 iPhone 上可以到「设置 → 相机 → 格式」选「最兼容」，之后拍的就是 JPEG。已经拍好的可以用 AirDrop 或邮件传给自己，那个过程多半会转成 JPEG。

**WebP、GIF、PDF**：目前都不支持。PDF 的 metadata 散在多个地方，有些还压在文件内部的数据流里，需要另外处理。

## 这一页不做的事

不做人脸模糊。那需要人脸检测模型，跟清除 metadata 是完全不同的一件事，也不该用同一个工具的名义混在一起。

不做的还有：拿掉 metadata 不等于照片就安全了。画面里的门牌、路标、制服、窗外的景色，那些都在图像本身，这一页不会动到它们。分享之前自己看一遍。

## 清完之后会实际打开一次

清好的文件会在浏览器里实际载入一次再交给你。视频会等到时长读得出来为止，那是改坏视频最典型的症状。如果这一页的程序把文件改坏了，那一步会拦下来并且明白告诉你，不会让你拿着一份打不开的照片离开。你的原始文件全程没有被动到。

## 离线可用

跟这一区其他工具一样，程序存进设备之后没有网络也能用。断网时照样能用，就是「文件没有偷偷送出去」最直接的证明。
