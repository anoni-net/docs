# :material-file-send-outline: 发一份简历出去

## 今天午夜的截止时间

简历是三个月前那一份改的。作品集分成三个 PDF，其中一份的第 4 页是前公司还没公开的内部画面。用手机补拍的两页证书是横的。对方要求一个文件，不接受三个附件。

搜索「PDF 合并」，第一页几乎全是免费的在线服务。把简历与作品集上传到陌生的服务器，换一份合并好的文件回来。其中一家的隐私政策写着处理完两小时内删除，那句话写得很清楚，同时代表那两个小时里完整的文件在别人的服务器上。

## 实际要做的三件事

用 [PDF 页面整理](pdf-pages.md)，三件事在同一页做完。

1. 三个文件一起拖进来，用「往前」、「往后」排出简历、作品集、证书的顺序。
2. 内部画面那一页不要，在该文件的页码栏打 `1-3, 5-`，第 4 页就被跳过。
3. 两页证书按「转正」。

按下生成之后，页面会把输出重新读进来一次，逐页比对页数、方向与尺寸跟你选的一不一样，对不上就不给下载。错的输出跟对的输出看起来一模一样，而多数人不会自己打开检查，等收件的人发现少了一页，文件已经发出去了。

## 附件的作者栏写着另一家公司

Word 或 PowerPoint 导出的 PDF，文档层字段常常写着你电脑的账号名称、公司名称、操作系统版本与精确到秒的创建时间。投递 A 公司而附件的作者栏写着 B 公司，是很容易发生的事，收件的人打开内容摘要就看得到。

整理出来的文件是新建的，标题、作者、主题、关键词、制作软件与创建时间全部留空。文件名固定是 `pages.pdf`，`简历_最终版_改3.pdf` 这种原文件名同样带着信息，改成你要的名字再发出。

## 黑色方块盖住的字还在文件里

作品集里的客户名如果是在 PowerPoint 上盖一个黑色方块再导成 PDF，那段文字仍然留在文件中。收文件的人复制粘贴就读得到，这是最常见的失败方式。

同一页的「看里面有什么」底下有一个搜索框。把客户名、案号或你以为已经遮掉的字粘贴进去，它会告诉你那段字还留在第几页。查出来还在的话，回到原始的 PowerPoint 文件把那几页删掉重做，不要在 PDF 上再盖一次。

## 照片的拍摄信息要更早处理

作品集里的照片会不会把 EXIF 与 GPS 坐标带进 PDF，取决于你用哪一套软件转换。要确定的话，在把照片放进 PowerPoint 之前先用[文件 metadata 清除器](strip-metadata.md)处理过，那一步在 PDF 生成之后就来不及了。

画面上看得见的东西也一样。作品集里的截图有同事的名字或客户的内部系统，先用[截图遮蔽](redact.md)填成实心黑再放进 PowerPoint。

## 这条路径不只用在投递简历

任何要交出去的 PDF 都走同一个顺序，整理页面、搜索确认、改文件名再发：

- 申诉或投诉的附件，对方要一份而你手上是分开扫的好几份
- 报销与核销，收据扫描件照顺序合并起来，方向不对的先转正
- 整份合同里对方只需要看附件三，其余页面没有理由一起发出去
- 投稿或申请，作品集抽掉还没公开的那几页再发

整条路径在你的浏览器里完成，文件没有离开设备。页面存进设备之后没有网络也能用，见[离线阅读](../offline.md)。
