NGO 的工作人员把捐款页面的网址贴进 LINE 群组，网址是从电子报里复制出来的，带着 `utm_source` 与 `mc_eid`。收到的人点进去，后台取得的不只是有人捐款，还包括是哪一封信、经过谁转发。清过的网址捐款照样成立，只是少了可以回溯到谁的痕迹。

## 网址后面那串参数泄漏了什么

你从 Facebook 点开一篇文章再复制网址，得到的会是这种形状：

```
https://example.com/article?fbclid=IwAR3xK9mQ...
```

`fbclid` 是 Meta 给该次点击的识别码。你把它贴进群组，每个点进去的人都带着同一个 ID 回到 Meta，于是链接是谁分享的、有多少人点、点的人是谁，都串成同一笔记录。

电子报的 `utm_source` 也一样，转发出去等于让收件人知道你订了哪份电子报。`mc_eid` 更直接，是 Mailchimp 的收件人识别码，对得回你的电子邮件地址。

## 转址包装

Google 搜索结果的链接，实际指向的网址跟你看到的不一样：

```
https://www.google.com/url?q=https%3A%2F%2Fanoni.net%2F&sa=U&ved=...
```

直接复制贴给别人的话，对方点进去会先经过 Google 一次。Facebook 的 `l.php` 与 Instagram 的外部链接也是同样做法。工具会把包装拆掉，只留真正的目的地。

## 真正的主机是谁

钓鱼网址的手法多半在主机名上，地址栏看起来都很像。工具把真正的注册域名单独标出来，其他部分才看得出是障眼法。三种常见写法：

- `google.com.evil.tw`：品牌放在子域名，真正的域名是后面的 `evil.tw`。子域名谁都能取这个名字。
- `paypal-secure.com`：在品牌旁边加字，注册的是另一个域名。
- `аpple.com`：第一个字母是西里尔字母的 а，显示出来跟拉丁字母一样。浏览器实际连的是 `xn--pple-43d.com`，工具会把 xn-- 解回显示形式，并指出同一段里混了两种字母系统。2017 年公开示范的 `аррӏе.com` 整段都是西里尔字母，也抓得到。

另外三种也会标出来：「@」前面那段是登录信息而非主机，浏览器连的是 @ 后面那一个。主机是 IP 地址。连到非默认的端口。

注册域名用一份常见的两段式后缀表判断（`com.tw`、`co.uk`、`github.io` 这类），不是完整的公开后缀清单，少见的域名可能多算或少算一段。判断是辅助，域名是不是你认识的那一家，最后还是要自己看。

## 只移除认得出来的参数

移除的逻辑是白名单：只拿掉清单里认得出来的追踪参数，其余一律保留。

反过来做的话，`?v=`（YouTube 的视频 ID）、`?page=2`、`?q=` 会一起被砍掉，你会取得一个打不开或指向错误内容的网址，而且不会联想到是清理工具改坏的，只会觉得对方给错了链接。YouTube 视频、分页、搜索这类常见网址都测过，需要的参数不会被误删。

每个被拿掉的参数旁边都会标示是谁在追，比单纯吐一个干净网址有用。下次你在别的地方看到 `gclid`，就知道是什么。

## 短网址不展开

`t.co`、`bit.ly` 等短网址得连上去才知道指向哪里。清理器刻意不做展开，因为展开等于把你想清理的网址送到第三方服务器，正是清理网址要避免的事。

要查短网址的目的地，用 [Tor Browser](../tools/what-is-tor.md) 开一次比较安全，对方至少看不到你的 IP。

## 离线可用

跟这一区其他工具一样，程序存进设备之后没有网络也能用。把网络关掉试一次，照样清得出来，代表你贴进去的网址不可能被送到任何地方。
