# :material-message-lock-outline: Signal 的设置与群组管理

Signal 是开放源代码、端对端加密的通信 App，文字、照片、语音频息、文件与语音视频通话都加密。Signal 向法院说明过，它能提供给执法机关的用户数据只有两项：账号创建的时间，以及账号最后一次连接的日期[^ssd-signal]。对话的双方都要安装 Signal，消息与通话走网络，不会产生短信费用。

Signal 的默认已经相当安全，本页整理装好之后还值得调整的设置，以及经营大型群组时的做法。Signal 跟其他通讯工具的比较见 [匿名通讯工具比较](./messaging-comparison.md)，端对端加密保护得到哪里、门号注册与安全码见 [端对端加密的保护范围](../basics/e2ee.md)。

本页依 EFF Surveillance Self-Defense 的〈How to: Use Signal〉与〈Creating and Managing Signal Groups〉两篇合并改写（出处见[本页的来源与核对](#本页的来源与核对)）。

!!! tip "时间有限的话，先看这几点"

    - 打开「注册锁定」，把 Signal PIN 码记下来，别人就无法用你的号码在另一支手机注册
    - 设置 username，把「谁可以通过电话号码找到我」改成「没有人」，对方就看不到你的号码
    - 敏感的对话打开「阅后即焚」，但对方仍然可以截屏
    - 经营大型群组时，先设好权限与管理员，群组链接打开「需要管理员批准」

## 安装与注册

在 Google Play 或 App Store 搜索 Signal 安装。在中国大陆，App Store 中国区自 2024 年 4 月起已下架 Signal，2021 年 3 月起也需要代理才能连接（见 [Signal Proxy](./signal-proxy.md)）。Signal 也有电脑版，但要先有手机上的账号才能链接，使用电脑版时记得替电脑设置高强度的登录密码并打开全碟加密（见 [设备加密与数据抹除](./device-encryption.md)）[^ssd-signal]。

注册时的几个选择[^ssd-signal]：

- **通讯录权限**：Signal 用私密的联系人比对机制找出通讯录里谁在用 Signal，上传的数据比对完就删除。不想分享通讯录可以拒绝，之后要手动输入号码才能开始对话
- **电话号码**：注册需要一个可以收短信验证码的号码。号码默认不会显示在个人资料上，除非对方的通讯录本来就存了你的号码。不想用主要的手机号，可以另外准备一个号码（手机号实名制的影响见 [端对端加密的保护范围](../basics/e2ee.md) 的〈Signal 的手机号与免手机号注册〉）
- **个人资料**：名字是必填，可以用假名，照片与姓氏可以不填。名字与照片会显示给你通讯录里的人、你打开或接受对话的人，以及你加入的群组
- **Signal PIN 码**：换手机时用来回复设置、个人资料与联系人，也是后面「注册锁定」要用的那一组
- **谁可以通过电话号码找到我**：默认是「所有人」，有你号码的人都会在 Signal 上找到你。改成「没有人」的话，要另外设置 username，对方才能开始跟你对话

## 日常使用

开新对话：在「聊天」分页点铅笔图标（Android 在右下角，iPhone 在右上角），选联系人或输入号码，也可以直接发起语音或视频通话。通话与消息一样是端对端加密，也可以创建「通话链接」分享给其他人加入[^ssd-signal]。

谈到敏感的事情之前，可以核对对方的安全码，确认密钥没有被替换：在对话中点对方的名字 >「查看安全码」，当面互扫 QR code 或念出数字比对，相符就点「标记为已验证」[^ssd-signal]。安全码变更时该怎么判断，见 [端对端加密的保护范围](../basics/e2ee.md) 的〈安全码的核对〉。

## 建议调整的设置

以下的路径都从聊天列表左上角的个人资料图标开始，iPhone 要先点「设置」，Android 直接进入。菜单名称依 Signal 的正体中文界面，iPhone 与 Android 偶有出入。

### 注册锁

打开之后，别人没有你的 Signal PIN 码，就无法用你的号码在另一支手机注册 Signal。PIN 码一定要记下来，换手机时忘了 PIN 码，至少七天无法登录自己的账号。位置在「账户」>「注册锁定」，还没创建 PIN 码的话先创建[^ssd-signal]。

### username 与电话号码的显示

username 的作用比较像「让人找到你的代号」，不是社区平台那种公开账号名称。设置之后，跟你对话的人看不到你的号码，除非他的通讯录本来就存了。username 结尾至少要有两位数字（例如 `anoni.01`），可以随时更改，已经开始的对话不受影响，但只有旧 username 的人就找不到你了[^ssd-signal]。

- **设置 username**：点最上方你的名字 >「用户名」，分享时可以产生 QR code 或链接
- **号码的显示**：「隐私」>「手机号码」，「谁可以看到我的电话号码」默认是「没有人」，「谁可以通过电话号码找到我」默认是「所有人」[^ssd-signal]

### 阅后即焚消息

消息在对方读取之后经过设置的时间，会从双方的设备上删除，倒数从对方打开消息开始算。担心家人或执法人员取得手机翻看时很有用，但对方仍然可以截屏或另外记录，这项功能防的是设备被取得，防不了对话的另一端[^ssd-signal]。

- **新对话的默认**：「隐私」>「阅后即焚」，选择时间
- **单一对话**：在对话中点对方或群组的名字 >「阅后即焚」
- **只能看一次的照片或视频**：选好照片或视频之后，点输入框上方的无限大符号，切换成「1」再发送，对方一样可以截屏[^ssd-signal]

### 通知显示的内容

锁屏上的通知可能让旁人不用解锁就看到消息内容，手机的 AI 通知摘要也会读取内容。在「通知」>「显示」选择「只显示名称」或「没有名字或者内容」[^ssd-signal]。

### 备份

Signal 提供端对端加密的备份，打开时会得到一组恢复密钥，Signal 拿不到这组密钥，弄丢了就无法还原备份[^ssd-signal]。

- **安全备份**：存在 Signal 的服务器上，免费方案包含全部的文字消息与最近 45 天的媒体，付费方案可以存到 100 GB 的媒体。每天备份一次，只能看一次的消息与 24 小时内会自动销毁的消息不会备份
- **设备上备份**：只有 Android 有，备份档存在手机上，只能还原到同一台 Android 手机

备份是一个新的攻击目标。曾有钓鱼攻击专门骗取 Signal 用户的恢复密钥，不过攻击者光有密钥还不够，还要能接管账号，所以「注册锁定」是更重要的防线。只是担心换手机时带不走消息的话，用 Signal 内置的设备移转也可以，但限同一种系统之间（iPhone 到 iPhone、Android 到 Android）。开了备份之后，不想被备份的对话可以设成 24 小时以内自动销毁[^ssd-signal]。

## 情况比较敏感时

以下的设置不是每个人都需要，处境的风险比较高时再依威胁模型挑选（见 [威胁模型如何创建](../basics/threat-model.md)）[^ssd-signal]。

- **屏幕锁定**：「隐私」>「屏幕锁定」，解锁手机之后打开 Signal 还要再验证一次
- **切换 App 时的画面**：iPhone 在「隐私」打开「在 App 切换器中隐藏屏幕」。Android 的对应功能是「屏幕安全功能」，打开后也无法在自己的手机上截屏，但挡不住对方截屏
- **链接预览**：「聊天」>「生成链接预览」，默认关闭。打开时网站会知道链接被分享到 Signal，带追踪参数的网址还可能让人推出你在跟谁对话
- **键盘**：Android 在「隐私」可以打开无痕键盘，降低部分键盘收集输入内容的机会，但挡不住恶意键盘。也顺便删掉系统设置里不再使用的第三方键盘
- **通话隐藏 IP 地址**：Signal 默认用点对点通话，可能让对方取得你的 IP 地址，不在你通讯录里的人来电时才会改经 Signal 的服务器转送。「隐私」>「高级」打开「始终使用转发通话」，所有通话都经服务器转送，代价是通话品质可能下降
- **已链接的设备**：「已关联设备」列出链接到这个账号的电脑与平板，定期检查，看到不认得的就点旁边的菜单「解绑」
- **动态**：「动态」里可以设置谁看得到「我的动态」、关闭「浏览回执」，或直接「关闭动态」
- **变更电话号码**：换了手机号，或决定改用另一个号码时，在「账户」>「更改手机号码」
- **代理服务器**：Signal 在当地被封锁时，可以经由志工架设的代理服务器连接，消息仍然端对端加密，但代理服务器的经营者看得到你的 IP 地址。设置方式与社区自架的代理服务器见 [Signal Proxy](./signal-proxy.md)

## 群组的创建与管理

Signal 常被用在社运、互助与工会的组织工作。大型群组如果没有人管理，很容易混乱，也容易出现过度分享、带来法律风险的对话[^ssd-groups]。

### 先知道技术的限制

群组里的任何消息都可以被截屏转传，有不认识的成员时，最好假设这件事会发生。端对端加密也挡不住有人取得并解锁成员的手机[^ssd-groups]。Signal 群组最多 1,000 人，成员多到你不认识每个人（大约 50 人以上），或群组链接公开分享之后，就把它当成社区平台，假设内容可能被转到群组以外，包括出现在警方的卷宗里[^ssd-groups]。

### 加入群组之前先检查自己的个人资料

所有群组的成员都看得到你的名字与照片。跟不认识的人在大群组里，可以换成不容易辨识身份的名字与照片，这件事要在加入或创建群组之前做，之后才改的话，群组的记录会留下变更。也顺便确认「谁可以看到我的电话号码」是你要的设置[^ssd-groups]。

反过来说，别人的名字与照片也是他自己取的，不一定是本名。不确定某个成员是谁时，点他的个人资料可以看到你们还同在哪些群组[^ssd-groups]。

### 邀请成员

- **直接加入**：点群组名称 >「添加成员」，从联系人加入。用号码或 username 一个个加，比较能确定群组里是谁
- **群组链接**：默认关闭，管理员可以在群组设置的「群组链接」打开，链接以 `https://signal.group` 开头。适合印在传单或活动上广发，风险较高的场合用只限邀请或短期的链接，活动之间「重置链接」，第一批人加入之后就关闭。打开「需要管理员批准」，新成员要管理员同意才能加入
- **现场建群**：在「群组链接」点分享，产生 QR code 让现场的人扫描加入

第一次对既有的群组打开群组链接时，先告诉成员，让大家有机会在新成员加入前检查自己的个人资料[^ssd-groups]。

### 权限与管理员

创建群组时就决定好规则，比事后补救容易[^ssd-groups]：

- **阅后即焚消息的时间**：创建群组时就设置。敏感的群组设成一天或一周，万一有成员的手机被取得，里面留下的消息也比较少
- **权限**：点群组名称 >「权限」，可以把「添加成员」、「编辑群组信息」、「发送消息」设成「仅限管理员」。全部设成只有管理员，就成了只能看公告的频道，成员仍然可以按表情回应，讨论另外开一个小群组
- **管理员**：超过几个朋友的群组，至少指定一两位信任的管理员。点成员的名字 >「设为管理员」。管理员要审核成员、处理冲突、移除成员、回答问题，工作量不小，先跟对方谈好，也可以轮替
- **群组规则**：点群组名称 >「添加群组描述……」，写下群组的用途、截屏与转传的规范、出问题时找哪位管理员。钉选的消息也会照自动销毁的时间消失
- **成员标签**：请成员在这个群组设置「成员标签」，例如所属的组织或地区，名字之外多一个辨识的线索

待审核的加入申请在群组设置的「请求与邀请」里。Signal 不要求实名，审核新成员要自己想办法，例如直接问对方，或请已经认识他的成员确认[^ssd-groups]。

### 移除成员

点群组名称 > 成员的名字 >「从群组移除」。移除成员不会删掉他手机上的旧消息，改短自动销毁的时间也不会。你自己在 24 小时内删除自己传的消息，所有成员的手机上都会一起删除。知道某位成员正在被刑事调查、或手机已经被扣押时，变更群组设置之前先咨询律师[^ssd-groups]。

### 通知与辨识成员

- **静音**：在聊天列表长按对话，点静音图标，大型群组可以先请成员这样做
- **文件夹**：Android 可以把对话分到不同的文件夹，例如工作、家人、社区
- **昵称**：点联系人的头像 >「昵称」，替同名或用假名的人取一个只有你看得到的名字，也可以加备注。Signal 看不到这些数据，但手机被取得时，备注可能泄漏对方的身份，风险高时备注写得笼统一点，或干脆不用[^ssd-groups]

社运组织的群组设计与隔离，见 [社运行动者的数字准备](../scenarios/activist.md) 的〈通信群组的设计与隔离〉。
