# :material-flask-outline: 实验区

这一区放还在验证中的东西。每一页对应一则 issue，用途是量出一组数字，回答「这条路走不走得通」。

三件事先说明：

- 这里的页面随时会改，也可能整个消失，不要从文章或外部链过来
- 验证完成的东西会搬进小工具区并且重写，这一区的版本是中间产物
- 跟小工具区一样，运算在你的设备上进行，没有任何数据送到服务器

## 现在有什么

- [设备之间直接传文件](webrtc-transfer.md)，量 WebRTC 在没有互联网的现场能传多快，对应 [issue #553](https://github.com/anoni-net/docs/issues/553){target="_blank"}

## 怎么回报

每一页都有导出记录的按钮，导出的文件贴回该页对应的 issue。导出前会把 IP 与 mDNS 名称遮掉。

测不成功也是结果。哪一种网络连不上、在哪一步卡住、信息看不看得懂，这些都要记下来。
