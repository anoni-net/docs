# :material-wifi-off: 离线阅读

如果你是因为没有网络连接被带到这里，你要找的那一页还没有存到这台设备上。之前浏览过的页面仍然读得到，回到上一页或从[首页](index.md)开始就可以。

这一页同时是离线内容的管理处。下面看得到设备上目前存了什么、可以自己挑要留哪些、也可以把它们全部清掉。

## 哪些内容会存在你的设备上

你第一次用一般浏览器打开这个站时，当前语言的核心章节（概念、工具、进阶、在地）就会在后台下载到设备的缓存里，不需要你另外安装任何东西。切换到其他语言时，那个语言的章节才会另外下载，所以设备上只会有你实际读过的语言。之后浏览过的页面同样会被存下来。

记者、行动者、LGBTQ、家暴这几类场景页**不在预先下载的范围内**，只有你自己点开过才会被存下来。这些页面留在设备上本身可能就是敏感信号，所以是否留存交给你决定。需要离线带着走的话，在上面的清单里自己勾起来就会存下来。

你在语言菜单选过的阅读语言也存在同一个地方，站台用它决定下次从首页进来时打开哪一个语言版本，除此之外不会拿去做别的事。站台不会读取浏览器报告的语言，那个值在 Tor Browser 上一律是英文，照着判断会把台湾读者带去英文版。

上面的「清除所有离线内容」会把站台存的与你自己选的一起清掉，并停止自动存新的东西。要恢复自动存，回到上面把开关打开即可。

那颗按钮清不掉的东西：浏览记录、DNS 缓存，以及你从站上下载过的文件。那些要在浏览器或系统设置里处理。Chrome 是设置的「清除浏览数据」，Firefox 是「清除最近的历史记录」并展开细项勾选「Cookie 和网站数据」。只勾「缓存的图片和文件」清不掉网站存储这一类。

## 站上内容有新版本时

站上有新版本时，页面顶端会出现一条提示，按下「立即更新」才会套用。这样安排是为了避免在你阅读的过程中把内容抽换掉。没有按也没关系，在线浏览一直都是最新内容，设备上的离线副本则维持原样，直到你按下更新。

## 可以试试

- 回到[首页](index.md)浏览已缓存的内容
- 检查 Wi-Fi 或移动网络是否正常
- 如果你身处网络被封锁或干扰的环境，恢复连接后可以参考[翻墙与审查规避工具](tools/index.md)

连接恢复后刷新此页，就会回到正常内容。
